## 1. 先想清楚一个问题

我在面包板上把 STM32 最小系统板跑起来之后，看到板子上有这么一组东西：

```text
   ┌──────────────────────────────────┐
   │  ┌──┐                            │
   │  │C │  ← 一颗小电容（棕色，无字）  │
   │  └──┘                            │
   │  ┌──┐                            │
   │  │C │  ← 又一颗，一模一样          │
   │  └──┘                            │
   │      [ 3.3V 稳压芯片 ]            │
   │  ┌──┐                            │
   │  │C │  ← 第三颗                    │
   │  └──┘                            │
   └──────────────────────────────────┘
        ┌──────────────┐
        │ STM32F103C8T6│   ← 这颗芯片有 4 个 VDD 脚 + 1 个 VDDA 脚
        │  VDD1  VDD2  │      每个脚旁边都能看到一颗 100nF
        │  VDD3  VDD4  │
        └──────────────┘
```

我当时的反应是：**电源本来就是稳的（万用表量上去 3.30V，一动不动），
为什么还要在每个电源脚旁边塞一颗电容？** 而且塞的还是
我们通常认为"跟电源完全相反"的东西——一个电容，直流根本不通。

更让我想不通的是：如果一定要加，**为什么是 100nF 加 10µF 两颗并联，
而不是直接一颗 10.1µF？** 从容量上看，`100nF + 10µF = 10.1µF`，
一颗 10.1µF 的电容在直流意义上是完全等价的。

后来我才明白，这两个问题的答案都指向同一个词：

> **电源不是"稳"，只是万用表说它稳。**

万用表测的是**平均值**，采样速度大概每秒几次。而芯片内部逻辑门翻转是
**纳秒级**的事。在这两个时间尺度之间，有一整个我完全没考虑过的世界 ——
走线的电感、电容的等效串联电感、电流的回路面积。这就是本章的主题：
**电源完整性（Power Integrity, PI）**。

那时候我还在准备 BNGU 战队的报名，看海报上写「围绕单片机设计机器人相关电路、
PCB 与制作调试」「整车电气集成与布线规范」。我当时觉得"布线规范"是个很虚的词，
直到我看懂了这个电容 —— 它是为了对付一个只有几纳秒宽、万用表永远看不到的
电压跌落。**"布线规范"就是围绕这些看不见的东西总结出来的经验。**

## 2. 原理：它到底是怎么工作的

### 2.1 为什么每个电源引脚旁边都要放电容

#### 2.1.1 芯片翻转时会发生什么

CMOS 逻辑门是"电压控制"的器件，但它在**切换状态的瞬间**必须
给后级栅极电容充放电 —— 这个电荷只能从电源上取。

设一个门每次翻转需要搬运的电荷是 `ΔQ`，翻转频率 `f`，
那么平均电流是：

```text
I_avg = ΔQ × f
```

对一颗 STM32F103 来说，内部有几万个门，还有各种驱动器（I/O 输出、
时钟树缓冲、ADC 电容开关）。**更要命的不是平均值，是瞬时值**：

```text
i(t) 的波形是一串很窄的尖峰，峰值可能是平均值的几十倍
```

真正决定电压跌落的是**电流的变化率** `di/dt`。

#### 2.1.2 走线电感：`ΔV = L · di/dt`

任何一段导线都有寄生电感。按经验值，**1mm 走线大约 1nH**
（具体值与线宽、离地平面距离有关，这个数量级是可靠的）🔬。

最小系统板上，从 3.3V 稳压芯片到 STM32 的 VDD 引脚，走线长度大约 30mm：

```text
L ≈ 30mm × 1nH/mm = 30nH = 30×10⁻⁹ H
```

再估一下 `di/dt`。假设 STM32 的一个 I/O 在驱动 20pF 负载（第 03 章算过边沿时间
大约几纳秒），从 0 充到 3.3V 的电荷是：

```text
ΔQ = C × ΔV = 20pF × 3.3V = 66pC
```

如果这个充电发生在 `t_r = 5ns` 内：

```text
di/dt ≈ ΔQ / t_r² = 66×10⁻¹² / (5×10⁻⁹)² = 66×10⁻¹² / 25×10⁻¹⁸ = 2.64×10⁶ A/s
```

（这个估法比较粗，量级是"百万安培每秒"这个级别，重点是量级。）

于是走线上产生的电压跌落：

```text
ΔV = L × di/dt = 30×10⁻⁹ H × 2.64×10⁶ A/s = 0.079V ≈ 79mV
```

**79mV。** 这只是一个 I/O 造成的。如果同时翻转 8 个 I/O（比如一次并口写操作），
量级上就是 `8 × 79mV = 632mV` —— **3.3V 的电源瞬间掉到 2.7V。**

而 STM32F103 数据手册里给的**推荐工作电压下限是 2.0V**（🔬 具体数值见
《STM32F103x8/B Datasheet》**第 5.2 节 Absolute maximum ratings** 与
**第 5.3 节 Operating conditions** 中 VDD 的 min/max），
所以 2.7V 还在范围内，但已经吃掉了一半裕量。

再看更坏的情况：如果这颗芯片还同时驱动着 LED、OLED、蜂鸣器，
电流尖峰更大，`ΔV` 就可能把 VDD 拉到复位门限以下 —— 这就是
**"板子跑着跑着随机复位"** 的经典原因之一（第 6 节会写这个坑）。

#### 2.1.3 去耦电容：本地电荷水库

解决思路只有一句话：**不要让这个尖峰电流去走那 30mm 的线。**

在 VDD 引脚旁边（紧贴着）放一颗电容：

```text
   3.3V 电源 ────────┬─────── 30mm 走线（有 30nH 电感）───────┐
                     │                                        │
                  ┌──┴──┐                                  ┌──┴──┐
                  │ 100nF│  ← 去耦电容，紧贴引脚              │ VDD │
                  └──┬──┘                                  │     │
                     │                                     │ STM │
                    GND                                    │ 32  │
                                                           └──┬──┘
                                                              │
                                                             GND
```

电容两端的电压不能突变（`i = C·dv/dt`，反过来说 `ΔV = ΔQ/C`）。
所以芯片翻转时需要的那个电荷 `ΔQ`，**优先从这颗就近的电容里拿**，
而不是从 30mm 外的稳压芯片那里拿。电流回路从"30mm 大圈"变成"2mm 小圈"，
回路上的电感从 30nH 降到大约 2nH。

重算一次跌落：

```text
ΔV = L × di/dt = 2×10⁻⁹ × 2.64×10⁶ = 5.3×10⁻³ V = 5.3mV
```

**从 79mV 降到 5.3mV，小了 15 倍。**（这个 15 倍就是电感比 30:2。）

再看这个电容"能供多少电荷"。`ΔQ = C × ΔV`，如果允许电压跌落 50mV：

```text
100nF 能提供的电荷 = 100×10⁻⁹ F × 0.05V = 5×10⁻⁹ C = 5nC
```

而我上面算的一个 I/O 翻转只需要 66pC = 0.066nC。**5nC 能支持 75 次这样的翻转。**
这正好说明它是"水库"而不是"电源"——它只能撑极短的时间，
但芯片的电流尖峰本来也是极短的，之后电源会通过那 30nH 的走线把电荷补回来。

#### 2.1.4 为什么"平均值很稳"和"瞬时很糟"能同时成立

因为万用表看到的和芯片看到的是两回事：

| | 时间尺度 | 万用表读数 | 芯片实际看到的 |
|---|---|---|---|
| 稳压芯片的环路响应 | 10µs ~ 100µs | 参与平均 | 太慢，来不及响应 ns 级尖峰 |
| 10µF 大电容 | µs 级 | 参与平均 | 能管 µs 级的需求 |
| 100nF 小电容 | ns~几十 ns 级 | 参与平均 | **管 ns 级尖峰，这一层最重要** |
| 走线电感 | — | 测不到 | 就是它制造的跌落 |

**关键结论：稳压芯片的反馈环路再快也是微秒级，而芯片需要的响应是纳秒级。
中间这个空档，只能由贴在引脚旁边的电容来填。** 这个"分层供电"的思路，
是整章电源设计的骨架。

### 2.2 100nF 和 10µF 为什么要并联（自谐振频率 SRF）

#### 2.2.1 一个真实电容不是电容

"电容"这个符号在教科书里是理想的，但实物是这样：

```text
        ┌─────── ESR（等效串联电阻）─────── ESL（等效串联电感）───────┐
        │                                                          │
   ○────┤                       C（真正的容性部分）                 ├────○
        │                                                          │
        └──────────────────────────────────────────────────────────┘

   ESR：介质损耗 + 电极电阻 + 引脚/焊盘电阻     单位 Ω，典型 mΩ ~ 百 mΩ
   ESL：电极结构 + 引脚 + 过孔的电感            单位 nH，典型 0.5nH ~ 2nH
```

于是这个"电容"的阻抗是三个元件串联：

```text
Z = ESR + jωL + 1/(jωC)
```

三项的频率特性完全不同：

- `1/(ωC)`：**随频率升高而下降**（容性）
- `ωL`：**随频率升高而上升**（感性）
- `ESR`：**不随频率变化**（一个常数下限）

**两者相交的那个频率，就是自谐振频率（Self-Resonant Frequency, SRF）。**

```text
令 |1/(ωC)| = |ωL|：

1/(ωC) = ωL
ω² = 1/(LC)
ω = 1/√(LC)

       1
SRF = ──────────
      2π√(LC)
```

#### 2.2.2 算一下 100nF 和 10µF 的 SRF

取 0603 封装 MLCC 的典型 ESL：（🔬 这两个 ESL 值取自厂商选型手册的
阻抗-频率曲线，具体数值我引用的是"该封装量级"的典型值，
实际请查你用的那颗料的手册，见第 3 节）

- 100nF / 0603：`ESL ≈ 0.5nH`
- 10µF / 0805：`ESL ≈ 1nH`（大容量封装更大，ESL 更大）

**100nF 的 SRF：**

```text
L × C = 0.5×10⁻⁹ H × 100×10⁻⁹ F = 5×10⁻¹⁷
√(L×C) = √(5×10⁻¹⁷) = 7.071×10⁻⁹ s
SRF = 1 / (2π × 7.071×10⁻⁹) = 1 / (4.443×10⁻⁸) = 2.251×10⁷ Hz ≈ 22.5MHz
```

**10µF 的 SRF：**

```text
L × C = 1×10⁻⁹ H × 10×10⁻⁶ F = 1×10⁻¹⁴
√(L×C) = √(1×10⁻¹⁴) = 1×10⁻⁷ s
SRF = 1 / (2π × 1×10⁻⁷) = 1 / (6.283×10⁻⁷) = 1.592×10⁶ Hz ≈ 1.59MHz
```

**两个数差了 14 倍：22.5MHz vs 1.59MHz。**

#### 2.2.3 SRF 之后会发生什么（这是关键）

画出阻抗-频率曲线（都是对数坐标，双对数下是一条 V 形线）：

```text
|Z| (log)
  ▲
  │
1Ω├─╲                                              ╱
  │   ╲                                          ╱
  │    ╲           容性区（斜率 -1）             ╱  感性区（斜率 +1）
  │     ╲                                      ╱
0.1Ω      ╲                                  ╱
  │         ╲                             ╱
  │          ╲                         ╱
  │           ╲___________________╱
ESR├───────────────┴───────────  ← 谷底 = SRF，此处 |Z| = ESR
  │              SRF
  └────┬────┬────┬────┬────┬────┬────┬────▶ f (log)
     10k  100k  1M   10M  100M  1G
```

**在 SRF 左边**，电容是容性的，频率越高阻抗越低 —— "电容"在正常工作。
**在 SRF 右边**，`ωL` 占了主导，**阻抗随频率升高反而变大** ——
这时候这颗"电容"已经变成一颗电感了，**它对高频噪声完全无能为力。**

**而数字电路的噪声频谱恰恰覆盖到几百 MHz**（边沿 5ns 对应的频率成分是
`1/(π·t_r) ≈ 64MHz`，谐波还要往上）。所以：

- 一颗 10µF 的电容，在 1.59MHz 以上就开始失效，到了 100MHz 它的阻抗
  已经是 `2π×100MHz×1nH = 0.63Ω` 了，比低频时高了几百倍；
- 一颗 100nF 的电容，能一直管到 22.5MHz，到了 100MHz 它的阻抗是
  `2π×100MHz×0.5nH = 0.31Ω`，比 10µF 好一倍。

**所以大电容管低频、小电容管高频，这就是并联的理由。**

#### 2.2.4 为什么不能只用一颗 10µF

因为 10µF 的 SRF 只有 1.59MHz。在 STM32 的噪声主要频段
（几十 MHz 到几百 MHz）它已经呈感性了，帮不上忙。

**而且不能靠"把 10µF 换成更大的容量"来救**：

```text
把 C 从 10µF 加大到 100µF（ESL 假设还是 1nH）：

SRF = 1/(2π√(1×10⁻⁹ × 100×10⁻⁶)) = 1/(2π√(1×10⁻¹³))
    = 1/(2π × 3.162×10⁻⁷) = 503kHz
```

**容量变大，SRF 反而更低。** 大电容只能管更低的频率。
高频这一段，**必须靠小电容**。

#### 2.2.5 一个反直觉的结论：多个同值电容并联不能展宽频段

如果我在一个引脚旁边放 10 颗 100nF：

```text
并联后 C = 10 × 100nF = 1µF
并联后 ESL = 0.5nH / 10 = 0.05nH（并联电感也是并联）

SRF = 1/(2π√(0.05×10⁻⁹ × 1×10⁻⁶))
    = 1/(2π√(5×10⁻¹⁷))
    = 1/(2π × 7.071×10⁻⁹)
    = 22.5MHz
```

**SRF 还是 22.5MHz，一点没变。**

> **原因**：`SRF = 1/(2π√(LC))`。N 颗相同的电容并联，`C` 变成 `N·C`，
> `L` 变成 `L/N`，乘积 `L·C` 不变，所以 SRF 不变。
>
> 并联能降低的是 **SRF 附近的阻抗**（谷底深度从 `ESR` 变成 `ESR/N`），
> 但**不能移动谷底的位置**。

**结论：要覆盖更宽的频段，必须让电容的容值错开。**
典型组合是"一个数量级一个数量级地错开"：

| 容值 | 封装示例 | ESL（典型） | SRF（算出来的） | 负责频段 |
|---|---|---|---|---|
| 10µF | 0805 | 1nH | 1.59MHz | 低频、大电流缓变 |
| 1µF | 0603 | 0.6nH | 6.5MHz | 中频 |
| 100nF | 0603 | 0.5nH | 22.5MHz | **主力**，中高频 |
| 10nF | 0402 | 0.4nH | 79.6MHz | 高频 |
| 1nF | 0402 | 0.35nH | 269MHz | 最高频、射频场合 |

⚠️ **一个要注意的反效果：并联会产生反谐振峰。**
不同容值的两个电容并联时，在它们 SRF 之间的某个频率上，
一个呈感性、一个呈容性，会形成 LC 并联谐振，阻抗出现一个**尖峰**。
如果这个尖峰刚好落在你的噪声频段上，**加电容反而让情况变糟**。
工程上的规避办法是：容值不要只差 10 倍，或者用多个接近的容值堆出平坦区。
这一点在设计严格的板子上要用仿真（如 Ansys SIwave）来看，我用计算看不出来 🔬。

### 2.3 布局比选型更重要

这一节是我觉得最容易被忽略、但最影响成败的部分。

#### 2.3.1 回路面积决定 EMI

电流永远是**一个环**。从电源流出，经过芯片，回到地，回到电源。
这个环围出的面积叫**回路面积（loop area）**。

安培定律的推论：**回路面积越大，这个环对外辐射的电磁场越强，
同时它接收外部磁场干扰的能力也越强。**

```text
   小回路（好）                          大回路（差）
   ┌──[芯片]──┐                       ┌────[芯片]────┐
   │          │                       │              │
  [C]        │                      [C]             │
   │          │                       │              │
   └──────────┘                       └──────────────┘
   面积 ≈ 2mm × 2mm                    面积 ≈ 30mm × 5mm
                                    （多了 37 倍）
```

辐射强度大致正比于回路面积（在远场、尺寸小于波长的条件下）：

```text
回路面积从 4mm² 变成 150mm²，辐射能力差 37 倍 = 31dB
```

**31dB 是一个巨大的差别。** 在 RoboMaster 这种"车上同时有几百瓦的电机驱动、
十几个传感器、2.4G/5G 图传"的环境里，EMI 差 31dB 就是从"能用"
到"随机死机"的距离。

#### 2.3.2 去耦电容的布局规则

```text
   ❌ 错误（电容离得远）                ✅ 正确（电容紧贴）

      ┌─── VDD 引脚                        ┌─── VDD 引脚
      │                                    │
      │  15mm 走线  ← 这段电感是 15nH        └─┬─ 走线 <2mm
      │                                      │
   ┌──┴──┐                              ┌────┴────┐
   │100nF│                              │  100nF  │  ← 电容紧贴引脚
   └──┬──┘                              └────┬────┘
      │                                      │
      │  15mm 走线                        ┌──┴──┐
      │                                   │ 过孔 │ ← 就地打地过孔
     GND（机壳地，很远）                    └──┬──┘
                                             GND 平面
```

我给自己的四条规则（都是从"回路面积最小"这一条推出来的）：

| 规则 | 具体做法 | 为什么 |
|---|---|---|
| 1. 电容贴引脚 | 电容到引脚的走线 **< 2mm** | 每 1mm 是 1nH，2mm 就只有 2nH，跌落比 30mm 小 15 倍 |
| 2. 先过电容再进引脚 | 电源走线**先进电容的焊盘，再从焊盘进引脚**（不要从旁边分支出去） | 这样电流路径是"电源→电容→引脚"，电容强制参与，回路面积最小 |
| 3. 就近打地过孔 | 电容的 GND 端**紧挨着**打一个过孔到地平面，距离 < 1mm | 地那一段也是回路的一部分，地过孔远了等于白做 |
| 4. 电源过孔也靠近 | VDD 的电源过孔同样就近打 | 同理，别让电源路径绕远 |

**规则 2 的示意图**（这一条最容易被做错）：

```text
   ❌ 分支式（电容像挂件一样挂在旁边）      ✅ 穿越式（电流必须经过电容）

     ───────●──────────── VDD 引脚           ───────●────[C]────●──── VDD 引脚
            │                                       （从焊盘穿过）
           [C]
            │
           GND

   电流可以选择走电容、也可以不走          电流只能从电容焊盘上过
   （走线电阻比电容 ESR 小，实际大部分不走）
```

#### 2.3.3 地平面与回流路径

**信号电流不是"从源流到负载就结束了"，它一定会流回来，
而且回流电流走的是"回路面积最小"的路径。**

在高频下，这个"最小面积路径"就是**信号走线正下方的地平面上**：

```text
   信号走线 ──────────────────────────────▶
   ═══════════════════════════════════════   ← 地平面
   回流电流 ◀──────────────────────────────
              （紧贴信号线正下方，走相反的路径）

   这样形成的回路面积 = 走线长度 × 走线到地平面的距离
   距离只有 0.2mm（介质厚度）→ 面积非常小 → EMI 小、抗干扰强
```

**如果地平面被切断了会怎样？** 回流电流不能从信号线正下方过去，
只能绕一个大圈找别的路回家：

```text
   信号走线 ──────────▶  ┌──── 地平面被一条缝切断
                        │
   回流电流必须绕行 ◀────┘   ← 绕这一圈，回路面积暴增
```

**结果是：回路面积从"长度 × 0.2mm"变成"长度 × 几 mm 甚至几十 mm"，
EMI 陡增，同时还会有信号完整性问题（阻抗突变、反射）。**

这就解释了**为什么双层板要"一面尽量铺完整地"**：

- 双层板只有两层铜，做不了"信号层—地平面—电源层"的三明治结构；
- 所以退而求其次：**一面尽量少走线、大面积铺地（灌铜），
  把信号线集中在另一面**；
- 关键的高频线（晶振、USB、SWD、SPI）下方必须有**连续的地**，
  绝对不能在它正下方横穿一条别的信号线。

⚠️ **一个具体例子：STM32 的晶振（HSE 8MHz）**。
晶振走线虽然只有 8MHz，但它的边沿很陡，谐波要到几百 MHz。
板子上 ST 的参考设计会在晶振周围放一圈接地过孔、下方铺完整地，
就是为了给这个高频回路一个"紧贴"的回家路。

### 2.4 LDO 与 DCDC 的取舍

#### 2.4.1 LDO 的效率：一个残酷的公式

低压差线性稳压器（Low Dropout Regulator, LDO）本质上是**一个自动调节的可变电阻**，
它把多余的电压"吃掉"变成热。所以：

```text
输入功率  P_in  = Vin × I_load
输出功率  P_out = Vout × I_load
损耗功率  P_loss = P_in − P_out = (Vin − Vout) × I_load

效率 η = P_out / P_in = Vout / Vin
```

**注意：LDO 的效率只跟电压比有关，跟电流无关。**
（因为电流在输入和输出是同一个 `I_load`，约掉了。）

**算一个我实际会遇到的场景：12V 降到 3.3V，带 500mA 负载。**

```text
P_out  = 3.3V × 0.5A = 1.65W
P_in   = 12V  × 0.5A = 6.0W
P_loss = (12 − 3.3) × 0.5 = 8.7 × 0.5 = 4.35W

η = 1.65 / 6.0 = 0.275 = 27.5%
```

**4.35W 全部变成热，效率只有 27.5%。**

#### 2.4.2 4.35W 有多热：算结温

这一步必须算，否则"加了散热片"就是拍脑袋。

设 LDO 封装是 TO-220（比如 LM1117 这一类的常见封装）：

| 热阻参数 | 符号 | 典型值 | 出处 |
|---|---|---|---|
| 结到壳热阻 | `Rθ_JC` | ≈ 5 °C/W | 器件数据手册的 Thermal Characteristics 表 |
| 壳到环境（加散热片） | `Rθ_CA` | 视散热片而定 | 散热片规格书 |
| 结到环境（**不加散热片**） | `Rθ_JA` | ≈ 50 °C/W | 器件数据手册，TO-220 无散热片 |

⚠️ 上面这些热阻数值是**通用量级**，具体必须以你用的那颗 LDO 的数据手册
Thermal Characteristics 表为准（不同封装差很多：SOT-223 大概 60~100 °C/W，
TO-252 大概 40~50 °C/W，DFN 带散热焊盘可以低到 10 °C/W 级）。

**不加散热片（`Rθ_JA = 50 °C/W`），环境温度 25°C：**

```text
T_junction = T_ambient + P_loss × Rθ_JA
           = 25°C + 4.35W × 50°C/W
           = 25 + 217.5
           = 242.5°C
```

**242.5°C。** 而一般塑封器件的最大结温是 **125°C 或 150°C**
（🔬 见器件数据手册 Absolute Maximum Ratings 里的 `T_J` max）。
**超出上限 100°C 以上，芯片内部会热保护关断，或者直接烧掉。**

**加一个 `Rθ_CA = 10 °C/W` 的散热片：**

```text
T_junction = 25 + 4.35 × (5 + 10) = 25 + 65.25 = 90.3°C
```

**90.3°C，勉强进了 125°C 以内，但余量只有 35°C。**
如果机箱里环境温度是 50°C（机器人内部很常见）：

```text
T_junction = 50 + 65.25 = 115.3°C    ← 几乎顶到 125°C
```

**结论：12V 降到 3.3V 带 500mA，用 LDO 是设计错误。**
不是"要加散热片"，是**这个方案本身不该用**。

#### 2.4.3 DCDC 的效率与代价

开关电源（DCDC，通常是降压型 buck）用"电感储能 + 高频开关"来转换电压，
理想情况下不消耗多余的电压：

```text
理想 buck：Vin × I_in = Vout × I_out   →   I_in = I_out × (Vout/Vin)
12V → 3.3V、0.5A 时：I_in = 0.5 × (3.3/12) = 0.1375A

理想效率 100%，实际考虑开关损耗、导通损耗、磁芯损耗，典型 85% ~ 95%
```

按 90% 算：

```text
P_in = P_out / η = 1.65W / 0.9 = 1.833W
P_loss = 1.833 − 1.65 = 0.183W

对比 LDO 的 4.35W：损耗降到 1/24
```

**0.183W 在 SOT-23-6 或 QFN 封装上几乎不需要额外散热。** 这是巨大的优势。

**DCDC 的代价：**

| 代价 | 具体表现 | 什么时候要命 |
|---|---|---|
| **开关纹波** | 输出有几十 mV 到上百 mV 的开关频率纹波（典型 300kHz~2MHz） | **给 ADC 参考、给模拟传感器供电时会污染测量结果** |
| **开关噪声** | 开关节点（SW）是高 `dv/dt` 节点，通过寄生电容耦合到周围 | 挨着晶振、ADC、运放时会变成干扰源 |
| **需要外围器件** | 电感、输入输出电容、反馈电阻，占板面积比 LDO 大 | 空间紧张时 |
| **EMI** | 开关动作本身就是辐射源，布局不好会过不了认证 | 严格场合要加屏蔽、加 snubber |
| **设计复杂度** | 环路稳定性、电感选型、布局敏感 | 新手容易做成"能出电压但不稳" |

#### 2.4.4 RM 上的实际选择逻辑

按我理解（这是设计思路，不是我实测的战队方案）：

```text
  24V 电池（或超级电容组）
        │
        ├──[ DCDC 降压 ]──▶ 12V ──▶ 电机驱动 / 舵机
        │      主电源用 DCDC：效率 90%+，电流大，纹波靠后级滤
        │
        ├──[ DCDC 降压 ]──▶ 5V ──▶ 外设（OLED、传感器总线）
        │
        └──[ LDO 二次稳压 ]──▶ 3.3V ──▶ STM32 数字部分
                                │
                                └──[ LDO / 基准 ]──▶ 3.3V 模拟（VDDA / VREF+）
```

**为什么最后一级用 LDO 而不是继续 DCDC？**

1. **压差小**：5V → 3.3V，压差只有 1.7V。带 200mA 时损耗是
   `(5 − 3.3) × 0.2 = 0.34W`，效率 `3.3/5 = 66%`。
   效率不高，但**绝对损耗只有 0.34W**，可以接受。
2. **纹波是关键指标**：STM32 的 ADC 参考电压直接决定测量精度。
   第 03 章算过 `1 LSB = 806µV`，如果 VREF 上叠着 50mV 的开关纹波，
   读数就在 ±60 LSB 里乱跳。**LDO 的电源抑制比（PSRR）能把这个纹波再压 40~60dB。**
3. **模拟电源要跟数字电源分开**：STM32 有独立的 VDDA/VREF+ 引脚，
   就是给这种"数字开关噪声 vs 模拟精度"的矛盾留的后路。
   ST 的硬件设计指南（第 3 节的 AN2586）里明确建议：
   VDDA 通过一个磁珠或小电感从 VDD 取，**并且单独去耦**。

**一句话总结这个取舍：**

> **大压差、大电流 → DCDC（因为 LDO 的损耗按压差×电流算，扛不住）。
> 小压差、对纹波敏感 → LDO（因为 DCDC 的开关噪声会污染测量）。
> 这两个条件在机器人上同时存在，所以是"两级串联"的结构，不是二选一。**

### 2.5 线宽与电流

#### 2.5.1 IPC-2221 的经验公式

PCB 走线能过多少电流，标准依据是 **IPC-2221**
《Generic Standard on Printed Board Design》，里面给出的是
"载流能力 vs 温升 vs 铜箔截面积"的曲线图。

外层走线（external layer）的经验公式：

```text
               0.44        0.725
I = k × (ΔT)      × (A)

其中（外层）：k = 0.048
     I  ：允许电流，单位 A
     ΔT ：允许温升，单位 °C（常用 10°C）
     A  ：铜箔截面积，单位 mil²（1 mil = 0.0254mm）
```

#### 2.5.2 算一条 1mm 宽、1oz 铜的走线

**先算截面积。**

1oz 铜的意思是"1 盎司铜均匀铺在 1 平方英尺上"，
对应的厚度是 **35µm = 1.378mil**（🔬 这是行业标准换算值）。

```text
线宽 1mm = 1/0.0254 mil = 39.37mil
截面积 A = 39.37mil × 1.378mil = 54.25 mil²
```

**代入公式，取 ΔT = 10°C：**

```text
A^0.725 = 54.25^0.725

先取对数：ln(54.25) = 3.994
乘 0.725：3.994 × 0.725 = 2.896
取指数：e^2.896 = 18.10

ΔT^0.44 = 10^0.44 = e^(0.44 × ln10) = e^(0.44 × 2.3026) = e^1.0131 = 2.754

I = 0.048 × 2.754 × 18.10 = 2.393 A
```

**算出来是 2.39A。** 而工程上大家记的经验值是"**1mm 线宽约 1A**"。

**为什么经验值比公式小一半多？** 因为经验值留了余量，原因有几条：

- 公式算的是"裸铜在静止空气中的温升"，实际走线上面盖着阻焊层、下面可能贴着板，
  散热条件更差；
- 公式不考虑**过孔**（过孔是载流的瓶颈，一个 0.3mm 孔径的过孔大概只能过 0.5~1A）；
- 公式不考虑**工艺偏差**（实际铜厚可能是 30µm 而不是 35µm）；
- 还要留余量和降额。

**所以我自己的做法是：按经验值 1A/mm 设计，需要更大的余量就加宽或者用 2oz 铜。**

#### 2.5.3 不同线宽的对照表（1oz 铜，ΔT = 10°C，按上面的公式算）

| 线宽 | mil | 截面积 (mil²) | 公式算出的电流 | 我实际会用的降额值 |
|---|---|---|---|---|
| 0.2mm | 7.87 | 10.85 | 0.715A | 0.3A |
| 0.3mm | 11.81 | 16.28 | 0.939A | 0.4A |
| 0.5mm | 19.69 | 27.13 | 1.337A | 0.56A |
| **1.0mm** | 39.37 | 54.25 | 2.393A | **1.0A** |
| 2.0mm | 78.74 | 108.5 | 3.979A | 1.66A |
| 3.0mm | 118.1 | 162.8 | 5.18A | 2.16A |

> 表格里的"公式算出的电流"是按 `I = 0.048 × 10^0.44 × A^0.725` 算的，
> "降额值"是我按经验取 1A/mm 折算的（即 ≈ 公式值 × 0.42）。

**要过大电流怎么办？四个办法（按优先级）：**

1. **加宽 + 用 2oz 铜**：2oz 铜厚度翻倍，同样线宽载流能力大约提升 `2^0.725 = 1.65` 倍。
2. **多层并联**：同样的网络在多层上走，载流能力叠加。
3. **开窗加锡**：在阻焊层开窗，走线上堆一层锡，等效截面积可增大 2~3 倍。
4. **直接用铜排 / 粗导线**：机器人上几十安培的主回路，
   通常根本不是 PCB 走线，而是**导线 + 接线端子**。

**再算一个具体例子的压降**，看线宽到底影响多大。

铜的电阻率 `ρ = 1.72×10⁻⁸ Ω·m`（20°C）。一条 1mm 宽、35µm 厚、50mm 长的走线：

```text
截面积 S = 1mm × 0.035mm = 0.035 mm² = 0.035×10⁻⁶ m² = 3.5×10⁻⁸ m²

R = ρ × L / S = 1.72×10⁻⁸ × 0.05 / 3.5×10⁻⁸
  = (1.72 × 0.05) / 3.5
  = 0.086 / 3.5
  = 0.02457 Ω ≈ 24.6mΩ
```

（也可以按"每毫米"来记：`24.6mΩ / 50mm = 0.49mΩ/mm`。）

**过 1A 时的压降和损耗：**

```text
ΔV = I × R = 1A × 0.0246Ω = 24.6mV
P  = I²R = 1² × 0.0246 = 24.6mW
```

24.6mV 的压降、24.6mW 的发热，都不大。**但如果是 5A 呢？**

```text
ΔV = 5 × 0.0246 = 123mV
P  = 25 × 0.0246 = 0.615W
```

**0.615W 集中在 50mm × 1mm 的一小条铜上**，温升就明显了。
如果是 20A（机器人上电机驱动的量级）：

```text
ΔV = 20 × 0.0246 = 0.49V      ← 半伏的压降，5% 的 12V 就没了
P  = 400 × 0.0246 = 9.85W     ← 一根走线烧 10W，必烧
```

**所以机器人上的大电流回路绝对不用 PCB 走线，而是用导线 + 接线柱。**
按 20A 反推需要的截面积：

```text
按 1A/mm 经验值，20A 需要 20mm 线宽（2oz 铜也要 12mm）
—— 这在 PCB 上是不可能的，所以只能用导线
```

**导线选多粗？** 按电流密度经验值：机内短距离、有风冷/有散热条件下
`4~6 A/mm²`。20A 需要：

```text
S = 20 / 5 = 4mm²  →  约 AWG 11（4.17mm²）
```

导线还有压降，`R = ρL/S`，1m 长的 4mm² 铜线：

```text
R = 1.72×10⁻⁸ × 1 / 4×10⁻⁶ = 4.3×10⁻³ Ω = 4.3mΩ → 20A 时压降 86mV
```

**这就是为什么机器人上的电源线又粗又短。** 每一米、每一个接头都在吃电压。

### 2.6 ⭐ 超级电容（Supercapacitor）

> 这一节是海报上明确点名的方向：「完成超级电容管理系统、无线充电模组」。
> **我要在开头说清楚：我此前完全没有接触过超级电容，也没做过任何实测。**
> 这一节是我查资料 + 按前面的物理原理自己推导的理解整理，
> 凡是需要实测才能确认的地方我都标了 🔬。
> **我不会假装我做过这个系统。**

#### 2.6.1 为什么 RM 需要它：规则约束下的"削峰填谷"

RoboMaster 的规则对**底盘功率**有上限（裁判系统会限制底盘电机的输出功率，
超功率会扣血）。这意味着：

- 机器人能持续从电池取用的功率是**被限制的**；
- 但机器人在某些瞬间（起步、急转、撞击）需要**远高于这个上限**的功率。

矛盾就在这里：**规则限制的是"持续功率"，而机器人的需求是"尖峰功率"。**

超级电容的作用就是在**规则允许的功率上限之内**，把平时用不完的能量
先攒起来，然后在需要爆发的那一瞬间放出去：

```text
功率
 ▲
 │          ╱╲   ← 需求尖峰（超过规则上限）
 │         ╱  ╲
 ├────────╱────╲────────  ← 规则允许的功率上限
 │       ╱      ╲
 │      ╱        ╲
 │ ────╱──────────╲───────▶ 时间
 │
 │  ╱╲╱╲╱╲╱╲╱╲╱╲╱╲  ← 超级电容充放电时的功率（在限值内波动）

   上限以上的部分由超级电容补，上限以下的余量给超级电容充
```

**能量账算一下。** 假设超级电容组是 `24V`、等效容量 `20F`，
工作电压从 24V 放到 18V（不能放太深，见 2.6.3）：

```text
可用能量 = ½ × C × (V_high² − V_low²)
        = ½ × 20F × (24² − 18²)
        = ½ × 20 × (576 − 324)
        = ½ × 20 × 252
        = 2520 J
```

**2520 焦耳。** 换算一下：

```text
2520J / 3.6×10⁶ J/kWh = 7×10⁻⁴ kWh = 0.7Wh
```

**0.7 瓦时。** 拿它跟电池比一下：一块 24V、5Ah 的锂电池是
`24 × 5 = 120Wh`。**超级电容组只有它的 0.58%。**

**所以超级电容不是用来"续航"的，它是用来"爆发"的。**
如果有人说"用超级电容让机器人跑更久"，那是理解错了 ——
真正的用法是"让机器人在那 0.5 秒的急加速里不掉功率"。

#### 2.6.2 超级电容 vs 锂电池：本质区别在哪

| 指标 | 超级电容（EDLC） | 锂电池（Li-ion / LiPo） |
|---|---|---|
| 储能机理 | **物理**：离子在电极表面形成双电层（不发生化学反应） | **化学**：锂离子嵌入/脱出晶格 |
| 能量密度 | 5 ~ 10 Wh/kg | 150 ~ 250 Wh/kg（差 20~30 倍） |
| **功率密度** | **10,000 ~ 15,000 W/kg** | 300 ~ 1,000 W/kg（**差 10~30 倍**） |
| 充放电循环寿命 | 50 万 ~ 100 万次 | 500 ~ 2,000 次 |
| 单体电压 | **2.7V**（部分 3.0V，超过会分解电解液） | 3.6~3.7V（磷酸铁锂 3.2V） |
| 充放电特性 | 电压随 SOC **线性**变化（`V = Q/C`） | 平台电压，中段几乎平坦 |
| 内阻 | **极低**，单体常 0.1~10mΩ | 较高，10~100mΩ 量级 |
| 过充耐受 | 超过额定电压会**电解液分解、产气、鼓包** | 过充会热失控、起火 |
| 温度范围 | -40 ~ +65°C，低温性能好 | 0°C 以下充电会析锂，伤电池 |
| 主要用途 | 能量回收、峰值功率补偿、瞬时备电 | 续航储能 |

**"能量密度低但功率密度极高"，这句话要理解成"内阻极低"。**

前面算过 `ΔV = I × R_ESR`，能不能大电流放电完全看 ESR：

```text
同样的 2.7V 单体：
  ESR = 10mΩ 的超级电容：允许压降 0.27V（10% 的 2.7V）
  → I_max = 0.27 / 0.01 = 27A   （单体！）

  ESR = 100mΩ 的锂电池：同样允许 0.27V 压降
  → I_max = 0.27 / 0.1 = 2.7A
```

**10 倍的差距，全部来自 ESR。** 这就是"功率密度差 10 倍"的物理来源。

⚠️ 但要注意：**"允许 27A"不等于"应该放 27A"**。
实际电流受限于封装引线、焊点、连接器，以及发热
（`P = I²R_ESR`，27A 时是 `27² × 0.01 = 7.3W`，一颗小单体烧 7.3W 会很快热起来）。
这些都要看具体器件的规格书 🔬。

#### 2.6.3 单体电压低 → 必须串联 → 必须均压

**为什么不直接用一节？** 因为一节只有 2.7V，而机器人母线是 24V。

```text
24V 需要几节串联：24V / 2.7V = 8.89 → 取 10 节（标称 27V，留出充电余量）
```

或者按"每节充到 2.7V 得到 27V 母线"来配，实际会做成 `9 或 10 节`。

**问题来了：串联的电容，电压怎么分？**

理想情况下均分：10 节串起来，每节 `27V / 10 = 2.7V`。**但实际不会均分**，原因：

1. **容量有差异**。超级电容的容量公差通常是 `−10% / +30%`（这比我预想的大得多 🔬
   请以具体规格书为准）。串联时电荷相同、容量不同 → `V = Q/C`，
   **容量小的那一节电压更高**。
2. **漏电流有差异**。每节都有微小的漏电流（μA 级），
   长期静置时漏电流小的那节电压会慢慢爬高。
3. **初始电压不同**。上次放电没放干净，或者某节自放电快一点。

**算一下最坏情况的危险程度。** 假设 10 节串联，
其中一节容量只有标称的 90%，其他都是 100%：

```text
充电到总电压 27V 时，电荷 Q 在每节是相同的。
容量偏小的那节：V = Q / (0.9C)   ← 电压是别的节的 1/0.9 = 1.111 倍

如果其他 9 节都是 2.66V，那一节就是 2.66 × 1.111 = 2.96V
```

**2.96V > 2.7V 额定。** 而超级电容超过额定电压会导致电解液分解、
产气、内阻上升、寿命暴跌，严重的会鼓包漏液。

**所以必须均压（balancing）。两种主流方案：**

```text
  ① 被动均压（passive balancing）—— 简单、便宜、发热

      ┌────┬────┬────┬────┐
      │ C1 │ C2 │ C3 │ C4 │ ...  每节一个并联电阻
      └─┬──┴─┬──┴─┬──┴─┬──┘
        │    │    │    │
       [R]  [R]  [R]  [R]   ← 每节并一个阻值相同的电阻（几十~几百Ω）
        │    │    │    │
        └────┴────┴────┘

   原理：电压高的那节，电阻上分到的电流大、泄放更多 → 电压被拉平


  ② 主动均压（active balancing）—— 复杂、高效、贵

      ┌────┬────┬────┐
      │ C1 │ C2 │ C3 │
      └─┬──┴─┬──┴─┬─┘
        │    │    │
      [ 双向 DC-DC / 电荷泵 ]   ← 把电荷从电压高的节搬到电压低的节
        │    │    │
        └────┴────┘

   原理：不浪费能量，效率高；但电路复杂、成本高、要控制芯片
```

**两种方案的取舍：**

| | 被动均压 | 主动均压 |
|---|---|---|
| 电路复杂度 | 每节一个电阻（甚至可以加一个稳压管/比较器） | 需要专用均压 IC 或自己搭 |
| 成本 | 极低 | 高 |
| 效率 | 差（多余的能量全变热） | 高（能量搬走而不是烧掉） |
| 发热 | 有，静置时也持续发热 | 只在工作时发热 |
| 适用 | 中小容量、对成本敏感 | 大容量、要求高 |

**被动均压的发热要算。** 10 节串联、每节并一个 `100Ω` 电阻，
充满时每节 2.7V：

```text
单节泄放电流 = 2.7V / 100Ω = 27mA
单节发热 = 2.7V × 0.027A = 0.073W
10 节合计 = 0.73W
```

**0.73W 一直在发热**，如果这是电池供电的设备，等于一直有个 0.73W 的负载。
所以被动均压的电阻不能选太小 —— **这是"均压速度 vs 静态功耗"的取舍**。

> **均压电路本身的设计（均压阈值选多少、用什么器件、怎么做过压保护），
> 我目前完全没有能力做，也不敢凭想象写电路图。**
> 这是我列在"短板"里的部分，需要先读懂一颗真实的超级电容管理 IC 的数据手册。

#### 2.6.4 缓启动（inrush current limiting）—— 这一节最重要

**问题：超级电容的容值太大了。**

上电瞬间，电容电压是 0V。如果把一个放完电的电容组直接接到电源上，
**在那一瞬间，电容对电源来说就是一个短路。**

电流只受回路总电阻限制。算一下 10 节串联的电容组：

```text
超级电容单体内阻：假设 10mΩ（🔬 具体看规格书，不同型号差很多）
10 节串联：R_cap = 10 × 10mΩ = 100mΩ
导线 + 接插件 + 保险丝 + 走线：假设 50mΩ

回路总电阻 R_total = 100 + 50 = 150mΩ = 0.15Ω
```

**上电瞬间（电容 0V），电源 24V：**

```text
I_inrush = 24V / 0.15Ω = 160A
```

**160 安培。** 后果：

- 30A 的保险丝**瞬间熔断**（保险丝的熔断曲线对 160A 大概是几毫秒级）；
- 如果没保险丝，接插件端子会打火、氧化、甚至熔焊在一起；
- 电源（DCDC 或电池 BMS）会被拉进过流保护，直接关机或者反复重启；
- 大电流在回路电感上产生巨大的 `L·di/dt`，可能击穿开关器件。

**方案 A：NTC 热敏电阻（负温度系数，Negative Temperature Coefficient）**

NTC 在**冷态**时阻值高、**热态**时阻值低。把它串在回路里：

```text
       电源 + ────[ NTC ]────┬──── 电容组 +
                            │
                          [需要缓启动的负载/板子]
                            │
       电源 − ─────────────┴──── 电容组 −
```

**冷态启动**（NTC 25°C 时阻值比如 5Ω）：

```text
I_inrush = 24V / (0.15 + 5)Ω = 24 / 5.15 = 4.66A
```

**从 160A 降到 4.66A，降了 34 倍。** 保险丝安全了。

**充电时间常数：**

```text
τ = R × C = 5.15Ω × 20F = 103 秒
```

⚠️ **103 秒太长了！** 5τ（充到 99.3%）要 515 秒 = 8.6 分钟。
这说明 NTC 方案对大容量超级电容**并不合适** ——
NTC 自身在几秒内就会因为 `I²R` 发热而阻值暴跌：

```text
4.66A 在 5Ω 上的发热 = 4.66² × 5 = 108W   ← 瞬间的
NTC 在毫秒~秒级就热了，阻值掉到 < 1Ω → 失去限流作用
```

**NTC 的优点**：便宜、简单、无源、不需要控制。
**NTC 的缺点**：只对"冷启动"有效（热机重启等于没有保护）、
反复上下电会失效、自身要消耗功率（稳态时 `I²R` 仍然发热）。
**所以 NTC 更适合"几百 µF 到几 mF 的输入电容"这种小场合，
对 20F 级别的超级电容不够用。**

**方案 B：PMOS + RC 缓启动（更正确的方法）**

用一个 P 沟道 MOSFET 串在回路里，栅极用 RC 网络慢慢拉低，
让 MOSFET 从"高阻"缓慢过渡到"完全导通"：

```text
                      ┌─────────────────┐
   24V+ ──────┬───────┤ S（源极）        │
              │       │   PMOS          ├──────┬────── 电容组 +
             [R1]     │ G（栅极）    D（漏极）
              │       └─────────────────┘      │
              ├────────┐                       │
              │        │                       │
             [R2]     [C1]                     │
              │        │                       │
              └────────┴───────────────────────┴────── 24V− / GND
                        （R2 ∥ C1 决定栅极下降速度）
```

**工作过程：**

1. 上电瞬间，栅极通过 `R1` 被拉到 24V（源极电平），`V_GS = 0` → **MOSFET 关断**；
2. 栅极通过 `R2` 缓慢放电（时间常数 `τ = R2 × C1`），`V_GS` 慢慢变成负值；
3. `V_GS` 越负 → MOSFET 沟道越开 → 等效电阻从"很大"平滑降到"几 mΩ"；
4. 电容组被"慢慢"充电，电流被 MOSFET 的沟道电阻限制住。

**算一下时间常数。** 取 `R2 = 100kΩ`、`C1 = 1µF`：

```text
τ = R2 × C1 = 100×10³ × 1×10⁻⁶ = 0.1 s

完全导通大约需要 3~5τ = 0.3 ~ 0.5 秒
```

**0.5 秒的缓启动，对机器人上电完全可接受。**

**那浪涌电流多大？** 这个数**不能只用上面的公式算**，因为 MOSFET
在过渡区是非线性的（`R_DS(on)` 随 `V_GS` 剧烈变化）。
正确的做法是查 MOSFET 数据手册里的 **SOA（Safe Operating Area，安全 work 区）曲线**，
确认在"漏源电压 24V、电流 X 安培、持续时间 0.5s"这个工作点是否在安全区内。

我按线性化粗估一下（🔬 **必须实测验证**）：

```text
假设 MOSFET 从关断到导通的平均等效电阻是 10Ω：
I_peak ≈ 24V / (0.15 + 10)Ω ≈ 2.3A
```

比 NTC 的 4.66A 还低，而且**稳态时 MOSFET 完全导通，
`R_DS(on)` 只有几 mΩ，几乎不发热、不损耗能量**。这就是它比 NTC 好的地方。

**PMOS 上的瞬时功耗要算**（这是选型的关键）：

```text
如果缓启动过程中，MOSFET 上同时有 10V 压降和 2.3A 电流：
P = 10V × 2.3A = 23W

持续时间假设 0.1s：
E = 23W × 0.1s = 2.3 J
```

**2.3 焦耳** 全部要在 MOSFET 的硅片里耗散掉。这时候必须查 SOA 曲线，
确认"24V × 2.3A × 0.1s"这个点安全。**这是我目前看不懂的部分之一** 🔬。

**方案 C：先小电阻预充，再短路（继电器 / MOSFET 旁路）**

```text
        ┌──[预充电阻 50Ω]──[继电器触点]──┐
        │                                │
   电源 ┼────────────────────────────────┼── 电容组
        │                                │
        └────────────────────────────────┘
```

先用 50Ω 电阻充电（`I = 24/50 = 0.48A`，很安全），
等电容电压升到接近电源电压时，用继电器把电阻短路掉。
时间常数 `τ = 50Ω × 20F = 1000 秒`，**太慢了**，所以这个方案对超级电容也不合适。

> **三个方案对照：**

| 方案 | 浪涌抑制 | 稳态损耗 | 重复上电 | 复杂度 | 适合的容量级 |
|---|---|---|---|---|---|
| NTC 热敏电阻 | 好（冷态） | 有（持续发热） | ❌ 热机失效 | 极低 | µF ~ mF |
| **PMOS + RC** | 好（可调） | 极低（几 mΩ） | ✅ | 中 | **F 级以上** |
| 预充电阻 + 继电器 | 好 | 极低 | ✅ 但慢 | 中 | 中等容量 |

**对超级电容这种 F 级的容量，PMOS 缓启动是主流方案。**

⚠️ **另外必须有的保护：保险丝。** 无论用哪种缓启动，
主回路都要有保险丝（或者用 BMS 的过流保护），
因为短路故障时的电流是无限大的，缓启动电路管不了故障。

#### 2.6.5 超级电容管理系统的组成（我理解的架构）

把上面这些串起来，我理解一个超级电容管理系统（CMS）大概是这四块：

```text
   ┌──────────────────────────────────────────────────────────┐
   │                    超级电容管理系统（CMS）                 │
   │                                                          │
   │  ① 电容组        ② 均压电路       ③ 缓启动 + 保护          │
   │  ┌──┬──┬──┐      ┌──┬──┬──┐      ┌────────────┐          │
   │  │C1│C2│C3│ ...  │R │R │R │ ...  │ PMOS 缓启动 │──▶ 母线  │
   │  └┬─┴┬─┴┬─┘      └┬─┴┬─┴┬─┘      │ 保险丝      │          │
   │   └──┴──┘         └──┴──┘        └────────────┘          │
   │                                                          │
   │  ④ 监测与控制（MCU）                                      │
   │     · 每节电压采样（多路 ADC / 专用 AFE）                  │
   │     · 总电压、总电流采样（霍尔 / 分流电阻）                 │

```

**第 ④ 块是我能做、也是我最想做的部分** —— 它用到的正是我在这个仓库里

**但它有一个我目前完全不会的难点：** 每节电容的电压采样是**浮地**的

不能用普通的单端 ADC 直接接，需要**差分采样 / 隔离 / 专用 AFE**。

#### 2.6.6 无线充电（Wireless Power Transfer, WPT）

> 同样，**我没做过任何无线充电的实测**。这里只写原理层面的理解。

**基本原理就是变压器，只不过把铁芯换成了空气。**

```text
   发射端（TX）                              接收端（RX）

   DC ──[逆变]── AC ──┐                  ┌── AC ──[整流]── DC
   高频方波            │                  │            给电池充电
                    ┌─┴─┐              ┌─┴─┐
                    │ L1│◀── 磁场 ──▶  │ L2│
                    └─┬─┘   （空气耦合） └─┬─┘
                      │                    │
                     GND                  GND
```

**关键区别**：普通变压器的耦合系数 `k ≈ 0.98`（磁通几乎全被铁芯约束），
空气耦合的线圈 `k` 只有 **0.1 ~ 0.5**（取决于距离和对齐程度）。
漏感非常大，所以必须用**谐振补偿**把效率救回来。

**谐振补偿（resonant compensation）**：

在发射和接收回路里各加一个电容，让 `L` 和 `C` 在开关频率上谐振：

```text
谐振频率： f₀ = 1 / (2π√(L·C))
```

**发射端串联谐振（Series compensation）**：

```text
   ┌──[C1]──[L1]──┐
   │              │
  交流源          磁场
   │              │
   └──────────────┘

   串联谐振时，L 和 C 的阻抗互相抵消（jωL + 1/(jωC) = 0），
   回路只剩线圈的等效串联电阻 → 同样的电压能送出更大的电流
```

**接收端并联谐振（Parallel compensation）**：

```text
   ┌──────┬──────┐
   │     [L2]    │
   │      │      │
   └────[C2]─────┘
         │
       整流

   并联谐振时，L 和 C 环流很大，但对外呈现高阻抗 → 适合做电流源输出
```

**为什么谐振能提高效率？** 因为线圈之间的漏感（`L_leak`）在非谐振时
会产生很大的无功压降，把可用电压"吃掉"了。谐振让它抵消，
**同样的输入电压能产生大得多的输出电流**，也就是能传更多的功率。

**效率随耦合系数和偏移距离快速下降 —— 这是这套方案最大的问题。**

耦合系数 `k` 随距离大致按幂律下降（短距离下接近 `k ∝ 1/d³` 量级 🔬
具体指数与线圈尺寸、形状、屏蔽有关）。传过去的功率近似正比于 `k²`：

```text
如果距离从 5mm 增加到 10mm，耦合系数按 1/d³ 下降：
k 变成原来的 (5/10)³ = 1/8

功率近似按 k² 变：
P 变成原来的 (1/8)² = 1/64
```

**位移 5mm，功率掉到原来的 1/64。** 这个数量级解释了为什么
无线充电必须"对准" —— 车上的线圈位置偏差几毫米，效率就从 80% 掉到 20%。

**实际系统的效率账**（🔬 这些是典型的量级，不是实测值）：

```text
DC → 高频逆变：       90%
逆变 → 发射线圈：      95%
线圈耦合传输：         70% ~ 90%（强耦合、对准良好）
接收线圈 → 整流：      92%
整流 → 电池充电：      95%

总效率 ≈ 0.90 × 0.95 × 0.80 × 0.92 × 0.95 = 0.597 ≈ 60%
```

**60% 左右。** 也就是说给电池充 100W，要从电源取 167W，
**67W 变成了热**。这些热在车内狭小空间里需要认真考虑散热。

**对 RM 这种场景，为什么还要用无线充电？**

我理解的原因是**接触可靠性**。机器人在赛场上要快速上下电、
要做防水防尘，物理接插件在震动、碰撞、潮湿下会氧化、松动、打火。
无线充电没有任何裸露触点，**省掉了这个机械失效点**。
代价就是效率低、要求对准、发热大。这是一个"用效率换可靠性"的取舍。

## 4. 完整代码

这段代码做三件事：

1. 用 ADC1_IN1（PA1）采样 12V 主电源经分压后的电压；
2. 做**滑动平均滤波**（不是第 03 章那种"采 32 次取平均"的块平均）；
3. 低于 **10.5V** 时点亮报警 LED。

> **说明**：`main.c` 是 STM32CubeMX 生成的骨架，我只在
> `/* USER CODE BEGIN */` 和 `/* USER CODE END */` 之间写代码。
> `printf` 重定向见 [第 05 章 串口通信](05-串口通信.md)。
>
> **引脚分配**（跟全仓库统一，不冲突）：
>
> | 功能 | 引脚 | 说明 |
> |---|---|---|
> | 报警 LED | PC13 | 板载 LED，**低电平点亮** |
> | 电源电压采样 | PA1 | ADC1_IN1 |
> | 串口 | PA9 / PA10 | USART1，115200 8N1 |
>
> **硬件连接**（分压电阻的算法见第 03 章 2.5 节）：
>
> ```text
>   12V 主电源 + ────[ R1 = 100kΩ ]────┬──── PA1（ADC1_IN1）
>                                      │
>                                   [ R2 = 10kΩ ]    ← 注意：这里用了 100k/10k，
>                                      │                 输出阻抗 9.09kΩ 偏大，
>                                      │                 所以采样时间必须设长
>                                     GND
>
>   分压比 = 10k/110k = 1/11 → 24V 时是 2.18V，仍在 3.3V 以内
> ```

```c
/* main.c —— 08 章：电源电压监测 + 滑动平均滤波 + 低压报警
 *
 * 硬件：PA1 (ADC1_IN1) ← 12V 电源经 100k/10k 分压（分压比 1/11）
 *       PC13 板载 LED，低电平点亮 —— 电压低于 10.5V 时点亮
 * 串口：USART1  PA9(TX) / PA10(RX)，115200 8N1
 *
 * CubeMX 生成：SystemClock_Config / MX_GPIO_Init / MX_ADC1_Init / MX_USART1_UART_Init
 * 我自己写的：USER CODE 之间的全部内容
 */

#include "main.h"
#include <stdio.h>
#include <stdbool.h>

ADC_HandleTypeDef hadc1;
UART_HandleTypeDef huart1;

/* ================= 我定义的参数，全部集中在这里 ================= */

/* ADC 参考电压。3.3f 是标称值，最准的做法是用万用表实测 VDDA 后填进来 🔬 */
#define VREF_VOLT        3.3f

/* 12 位 ADC 满量程码值 = 2^12 − 1 = 4095 */
#define ADC_FULLSCALE    4095.0f

/* 分压比 (R1+R2)/R2 = (100k+10k)/10k = 11
   12V 时 ADC 引脚 = 12/11 = 1.09V；24V 时 = 2.18V（仍 < 3.3V，安全） */
#define DIVIDER_RATIO    11.0f

/* 低压报警阈值：12V 电池放到 10.5V 就该提醒了
   （12V 铅酸/锂电的常见截止区），10.5V 对应 ADC 引脚 10.5/11 = 0.955V */
#define V_LOW_ALARM      10.5f

/* 报警恢复的迟滞（滞回，hysteresis）：回到 11.0V 才解除报警。
   没有这个 0.5V 死区的话，电压正好在 10.5V 抖动时 LED 会疯狂闪烁 */
#define V_ALARM_HYST     0.5f

/* 滑动平均窗口长度。取 8：窗口越大越平滑，但对突变的响应越慢
   （8 次采样 × 200ms 周期 = 1.6 秒的滞后） */
#define FILTER_WIN       8

void SystemClock_Config(void);
static void MX_GPIO_Init(void);
static void MX_ADC1_Init(void);
static void MX_USART1_UART_Init(void);

/* ================= 滑动平均滤波器 ================= */

typedef struct {
  uint16_t buf[FILTER_WIN];   /* 环形缓冲区，存最近的 N 个样本 */
  uint32_t sum;               /* 保留累加和，避免每次都重新遍历数组 */
  uint8_t  idx;               /* 下一个要写入的位置 */
  uint8_t  count;             /* 已经填了多少个（开头还没填满时用） */
} MovingAvg_t;

static MovingAvg_t g_avg = {0};

/* 往滤波器里塞一个新样本，返回当前的滑动平均值 */
static uint16_t MovingAvg_Push(MovingAvg_t *f, uint16_t sample)
{
  /* 先减掉将要被覆盖的那个旧样本（窗口没满时是 0，不影响） */
  f->sum -= f->buf[f->idx];

  f->buf[f->idx] = sample;
  f->sum += sample;

  /* 环形前进一格 */
  f->idx = (uint8_t)((f->idx + 1) % FILTER_WIN);

  if (f->count < FILTER_WIN)
  {
    f->count++;
  }

  /* 窗口还没满时除以实际个数，避免开头几拍被"拉低" */
  return (uint16_t)(f->sum / f->count);
}

/* ================= ADC 读取 ================= */

/* 读一次 ADC1_IN1 的原始码值（0~4095） */
static uint16_t ADC1_ReadRaw(void)
{
  uint16_t raw = 0;

  HAL_ADC_Start(&hadc1);
  HAL_ADC_PollForConversion(&hadc1, 10);          /* 超时 10ms */
  raw = (uint16_t)HAL_ADC_GetValue(&hadc1);
  HAL_ADC_Stop(&hadc1);

  return raw;
}

int main(void)
{
  /* ---------- CubeMX 生成的部分 ---------- */
  HAL_Init();
  SystemClock_Config();          /* HSE 8MHz × PLL9 = 72MHz */
  MX_GPIO_Init();
  MX_ADC1_Init();
  MX_USART1_UART_Init();
  /* ---------- 生成部分结束 ---------- */

  /* USER CODE BEGIN 2 */

  /* ADC 上电后必须校准一次，否则精度没有保证
     （RM0008 第 11 章 ADC，ADC calibration 小节） */
  HAL_ADCEx_Calibration_Start(&hadc1);

  printf("\r\n=== 08 power monitor ===\r\n");
  printf("VREF=%.3f V  divider=1/%.1f  alarm<%.2f V (hyst %.2f V)\r\n",
         VREF_VOLT, DIVIDER_RATIO, V_LOW_ALARM, V_ALARM_HYST);

  bool alarm_on = false;         /* 报警状态，带迟滞 */
  uint32_t tick  = 0;

  /* USER CODE END 2 */

  while (1)
  {
    /* USER CODE BEGIN 3 */

    /* ---- 1. 采样 + 滑动平均 ---- */
    uint16_t raw_now = ADC1_ReadRaw();
    uint16_t raw_avg = MovingAvg_Push(&g_avg, raw_now);

    /* ---- 2. 码值 → 引脚电压 → 还原到分压前的电源电压 ---- */
    float v_pin = (float)raw_avg * VREF_VOLT / ADC_FULLSCALE;
    float v_bus = v_pin * DIVIDER_RATIO;

    /* ---- 3. 带迟滞的低压判断 ----
       进入报警：v_bus < 10.5V
       解除报警：v_bus > 10.5 + 0.5 = 11.0V
       中间这 0.5V 是死区，状态保持不变 */
    if (!alarm_on && v_bus < V_LOW_ALARM)
    {
      alarm_on = true;
    }
    else if (alarm_on && v_bus > (V_LOW_ALARM + V_ALARM_HYST))
    {
      alarm_on = false;
    }

    /* PC13 是低电平点亮，所以报警时写 RESET(0)，正常时写 SET(1) */
    HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13,
                      alarm_on ? GPIO_PIN_RESET : GPIO_PIN_SET);

    /* ---- 4. 每 5 拍打印一次，避免刷屏太快看不清 ---- */
    if ((tick % 5) == 0)
    {
      printf("raw=%4u avg=%4u  v_pin=%.3f V  v_bus=%5.2f V  %s\r\n",
             raw_now, raw_avg, v_pin, v_bus,
             alarm_on ? "*** LOW VOLTAGE ***" : "ok");
    }
    tick++;

    HAL_Delay(200);              /* 5Hz 采样；实际测电源电压不需要更快 */

    /* USER CODE END 3 */
  }
}

/* ============ CubeMX 生成的初始化（我只在标 USER CODE 的地方动过） ============ */

static void MX_ADC1_Init(void)
{
  ADC_ChannelConfTypeDef sConfig = {0};

  hadc1.Instance                   = ADC1;
  hadc1.Init.ScanConvMode          = ADC_SCAN_DISABLE;
  hadc1.Init.ContinuousConvMode    = DISABLE;
  hadc1.Init.DiscontinuousConvMode = DISABLE;
  hadc1.Init.ExternalTrigConv      = ADC_SOFTWARE_START;
  hadc1.Init.DataAlign             = ADC_DATAALIGN_RIGHT;
  hadc1.Init.NbrOfConversion       = 1;
  if (HAL_ADC_Init(&hadc1) != HAL_OK)
  {
    Error_Handler();
  }

  /* 通道 1 = PA1。采样时间必须选最长的几档之一：
     分压网络输出阻抗 = 100k ∥ 10k = 9.09kΩ，
     需要约 654ns 的建立时间（第 03 章 2.5 节算过），
     55.5 周期 = 4.63µs，余量约 7 倍（ADCCLK = 72MHz/6 = 12MHz） */
  sConfig.Channel      = ADC_CHANNEL_1;
  sConfig.Rank         = ADC_REGULAR_RANK_1;
  sConfig.SamplingTime = ADC_SAMPLETIME_55CYCLES_5;
  if (HAL_ADC_ConfigChannel(&hadc1, &sConfig) != HAL_OK)
  {
    Error_Handler();
  }
}
```

**关于这个 `MovingAvg_t`，我想多说一句它和"块平均"的区别：**

第 03 章的 `ADC1_ReadAverage(32)` 是**块平均**：一次采 32 个然后算平均，
必须等 32 个采样全部做完才有输出。这里的结构是**滑动平均**：
每来一个新样本就吐出一个平均值，窗口在时间轴上"滑动"。

| | 块平均 | 滑动平均 |
|---|---|---|
| 输出频率 | 每 N 个采样出一次 | **每个采样都出** |
| 延迟 | N 个采样周期 | 约 N/2 个采样周期 |
| 内存 | 0（一个累加变量就够） | 需要 N 个样本的缓冲区 |
| 计算量 | 每次 N 次加法 | **每次 1 加 1 减**（用累加和） |
| 适合 | 一次性的测量 | **需要连续输出的监测（本章的场景）** |

**累加和 `sum` 这个技巧是关键**：如果每次都重新遍历缓冲区求平均，
计算量是 O(N)；用"减掉出去的、加上进来的"就变成 O(1) —— 常数时间。
代价是 `sum` 必须用 `uint32_t`：8 个 12 位样本最大是
`8 × 4095 = 32760`，`uint16_t`（最大 65535）**刚好够**，
但如果窗口改成 16 就会溢出（`16 × 4095 = 65520`，虽然还没超但已经在边缘）。
**所以我用 `uint32_t`，留出余量。**

## 5. 逐段解释

### 5.1 为什么报警阈值要带迟滞（hysteresis）

这是我在写代码时才想明白的一件事。不用迟滞会怎样？

假设电压正好停在 10.5V 附近，ADC 有 ±1 LSB 的抖动
（`3.3V/4095 = 806µV`，折回电源侧是 `806µV × 11 = 8.9mV`）：

```text
第 1 拍：读 10.504V → 不报警
第 2 拍：读 10.496V → 报警，LED 亮
第 3 拍：读 10.503V → 解除报警，LED 灭
第 4 拍：读 10.497V → 报警，LED 亮
...
```

**LED 以采样频率（5Hz）疯狂闪烁**，看起来像故障，实际电源完全正常。

加上 0.5V 的迟滞之后：

```text
进入报警需要 < 10.50V
解除报警需要 > 11.00V
中间 0.5V 宽的区间里，状态保持不变
```

那 0.5V 的死区比 8.9mV 的抖动大 **56 倍**，抖动完全被吃掉了。
**这是一个通用模式**：任何"阈值判断 + 执行动作"的地方，
只要被测信号有噪声，就要加迟滞（温控、电池低压保护、过流保护都是这样）。

### 5.2 为什么采样周期选 200ms

先算噪声：滑动平均窗口 8、每 200ms 一个样本，所以平均的是 1.6 秒的窗口。

电源电压的变化有多快？机器人上电池电压会随着电机加速而瞬时跌落，
这个跌落的时间尺度是几十到几百毫秒。如果我平均了 1.6 秒，
**这种快速跌落会被平均掉，报警就慢了。**

反过来说，如果采样太快（比如 1kHz），那我平均的是 8ms 的窗口，
滤波效果约等于没有，ADC 的抖动会全部透到报警逻辑里。

```text
窗口 8 × 200ms = 1.6s  ← 能滤掉 ADC 噪声，但对"电机起步导致的电压跌落"
                          响应偏慢（1.6s 后才完全反映出来）
```

**这个取舍没有唯一答案，取决于你要监测什么：**

| 目的 | 建议采样率 | 建议窗口 | 时间分辨率 |
|---|---|---|---|
| 电池电量估计（慢） | 10Hz | 16 | 1.6s |
| **低压报警（本章）** | **5Hz** | **8** | **1.6s** |
| 电机功率控制的电压前馈 | 1kHz | 4 或不用滤波 | 4ms |
| 捕捉瞬时跌落（示波器干的活） | — | — | — |

⚠️ **一个诚实的说明**：上面这张表的"建议值"是我根据"信号变化速度 vs 噪声"
推的工程判断，**不是实测调出来的**。
真要定这个参数，正确做法是用串口（或者示波器）把 `v_bus` 的原始值
按 1kHz 打出来，看噪声幅度和真实跌落的速度，再定窗口 🔬。

### 5.3 为什么用 `MovingAvg_Push` 返回的 `count` 而不是直接除以 `FILTER_WIN`

开机后的第 1 拍，缓冲区里只有 1 个有效样本，其余 7 个是 0。
如果直接除以 8：

```text
第 1 拍：真实值 4095，但 sum = 4095 + 0×7 = 4095
        4095 / 8 = 511   ← 只有真实值的 1/8！
```

**开机会有 7 拍（1.4 秒）读数严重偏低**，如果这时候正好触发报警逻辑，
就会误报警。所以要用 `count` 动态除：

```cpp
return (uint16_t)(f->sum / f->count);   /* 窗口没满时按实际个数除 */
```

第 1 拍就是 `4095 / 1 = 4095`，正确；第 8 拍之后 `count == FILTER_WIN`，
就变成正常的 `sum / 8`。

**这是一个很容易漏的边界条件。** 类似的坑在 PID 的积分项、
在滤波器的历史缓冲区、在任何"有初始化过程"的算法里都会出现。

### 5.4 `sum -= buf[idx]` 放在最前面为什么是对的

因为 `buf[idx]` 正是**要被覆盖掉的那个最旧的样本**（环形缓冲区，
`idx` 指向最老的位置）。所以顺序必须是"先减去旧的，再写入新的"。

如果写成先写后减：

```c
/* ❌ 错的顺序 */
f->buf[f->idx] = sample;              /* 旧值被覆盖了！ */
f->sum -= f->buf[f->idx];             /* 减掉的是新样本，减错 */
f->sum += sample;                     /* 又加了一遍新样本 */
```

结果就是新的样本被加了两次、旧的样本没被减掉，`sum` 会随着时间**单调增长**，
最后溢出、输出完全是垃圾。**这个 bug 的特点是"一开始看起来正常，
跑几分钟后才崩"**，特别难查 —— 因为它只在 `sum` 累积到溢出时才表现出来。

`uint16_t` 的 `sum` 在这个场景下尤其危险：正常值是 32760，
只要多加了几个样本就会超过 65535 直接回绕到 0。

### 5.5 为什么分压用 100k/10k 但采样时间必须设 55.5 周期

这两个数字是**绑定的**。第 03 章算过：

```text
R_out = 100k ∥ 10k = 9.09kΩ
τ = 9.09kΩ × 8pF ≈ 72.7ns
t_settle ≈ 9τ ≈ 654ns

ADCCLK = 12MHz → 1 周期 = 83.3ns
需要的周期数 = 654 / 83.3 = 7.85 → 至少 13.5 周期
我选 55.5 周期（4.63µs），余量 7 倍
```

**如果我为了"省电"把电阻改成 1M/100k（分压比还是 1/11）**：

```text
R_out = 1M ∥ 100k = 90.9kΩ
τ = 90.9k × 8pF = 727ns
t_settle ≈ 9τ = 6.5µs

55.5 周期 = 4.63µs < 6.5µs   ← 不够了！
最长档 239.5 周期 = 19.96µs > 6.5µs   ← 勉强够
```

**即使选最长的采样时间也只是"勉强够"，没有任何余量。**
所以 1M/100k 这种"省电设计"付出了"测量精度没有余量"的代价。

**更好的做法是把电阻降到 10k/1k**（第 03 章坑 3 的结论）：

```text
R_out = 909Ω，t_settle ≈ 65ns，55.5 周期有 70 倍余量
代价：从 12V 电源持续取 12V/11kΩ = 1.09mA
```

**1.09mA 值不值得？** 对一块 12V、5Ah 的电池（续航按小时算），
1.09mA 的静态负载可以忽略。**所以我倾向用 10k/1k，而不是 100k/10k。**
本节的代码保留了 100k/10k 是为了跟第 03 章的坑形成对照。

### 5.6 `HAL_Delay(200)` 和电源监测的矛盾

`HAL_Delay` 是**忙等式**的（它靠 SysTick 中断更新计数，然后死循环查询），
CPU 在等待期间什么都不干。对 5Hz 的采样率来说这是浪费，但无所谓 —— 
因为主循环里本来也没有别的事。

**但在真正的机器人代码里不能这么写。** 电源监测应该：

1. 用**定时器中断**（比如 TIM3 每 10ms 触发一次）来驱动采样；
2. 或者在主循环里"非阻塞"地判断时间：
   `if (HAL_GetTick() - last_tick >= 10) { ... }`；
3. 采样值用全局变量交给别的模块（CAN 上报、功率控制）用。

**原因**：机器人主循环里同时要跑 CAN 收发、姿态解算、PID 计算。
一个 `HAL_Delay(200)` 会把整个主循环卡住 200ms —— 
在这 200ms 里 CAN 报文可能丢、电机控制可能失步。
**这是我目前写"能跑的代码"和"能用在车上的代码"之间的最大差距** 🔬。

### 坑 1：板子跑起来随机复位，最后发现是去耦电容离芯片太远

**现象**：在面包板上搭好一套"STM32 + LED + 电位器 + OLED"之后，
板子能正常跑一串时间，但**随机复位**。复位的时间间隔不规律，
可能几十秒一次，也可能几分钟一次。用串口打点确认：
复位不是我代码里的逻辑触发的（我把所有 `NVIC_SystemReset()` 都注释掉了，
排除掉这个可能）。

**排查过程**：

| 步骤 | 怀疑对象 | 怎么排除的 | 结论 |
|---|---|---|---|
| 1 | 我的代码里有野指针 / 数组越界 | 把主程序换成一个空的 `while(1){}`，只点灯 | **还会复位** → 不是软件问题 |
| 2 | 电源电流不够 | 万用表量 3.3V 排针：稳定 3.29V | 万用表测的是平均值，**不能排除瞬时跌落** |
| 3 | 复位引脚 NRST 被干扰 | 在 NRST 上并一个 100nF 到地 | 复位频率**明显下降** → 有干扰，但没根治 |
| 4 | **去耦电容的位置** | 我把板子上自带的 100nF 拆掉，用杜邦线外接了一颗，**故意拉出 20cm 长的线** | **复位频率暴增** → 确认 |
| 5 | 换回短接线 | 把电容直接插在最小系统板 VDD 排针旁边（< 1cm） | **不再复位** ✅ |

**原因**（这一章 2.1 节算过）：

`ΔV = L × di/dt`。走线电感按 **1nH/mm** 估：

```text
20cm = 200mm 的杜邦线 → L ≈ 200nH

如果 di/dt = 2.64×10⁶ A/s（第 2.1.2 节算的量级）：
ΔV = 200×10⁻⁹ × 2.64×10⁶ = 0.528V

如果同时翻转多个 I/O，电流尖峰更大：
di/dt 到 10⁷ A/s 量级时，ΔV = 200nH × 10⁷ = 2V
```

**2V 的瞬时跌落，把 3.3V 打到 1.3V。** 而 STM32 的**上电/掉电复位（POR/PDR）
门限大概在 2.0V 上下**（🔬 具体数值见《STM32F103x8/B Datasheet》
第 5.3 节 *Reset and power control block characteristics* 表，
其中有 `V_POR` / `V_PDR` 的 min/typ/max）。
**低于门限就复位**，而且这个过程只有几纳秒，万用表永远看不到。

**为什么这个坑特别难查**：因为它依赖"哪些 I/O 在同时翻转"，
而这是软件运行状态决定的 —— 所以表现为"随机"。我一开始
一直在怀疑代码，方向完全错了。**"随机复位"要优先怀疑电源，而不是代码。**

**正确的做法**（就是 2.3.2 节的四条规则）：

1. 每个 VDD 引脚旁边一颗 100nF，**走线 < 2mm**；
2. 一颗 4.7µF~10µF 的电容做整体储能（放在电源入口）；
3. **面包板上做实验时，电容必须插在芯片旁边的同一排孔里**，
   不能拉长线；
4. NRST 引脚加 100nF 到地（这个我在第 3 步就做了，确实有效果，
   但它是"辅助"而不是"根治"）。

⚠️ **面包板本身就是一个很差的"PCB"**：它的每一排触点之间有寄生电容，
插线有几十 nH 电感，接触电阻也不稳定。
**所以面包板上能跑通的电路，不能证明它在 PCB 上也行；反过来，
在面包板上"莫名其妙不稳定"的电路，很可能在 PCB 上是好的。**
这一章 2.3 节的布局规则，就是为 PCB 准备的。

### 坑 2：电机一启动单片机就重启，地线走成了菊花链，改成星形接地才好

**现象**：把一个小直流电机接到同一块面包板上（电机由独立的电源供电，
但**共地**）。电机静止时一切正常，**一给电机上电，单片机立刻重启**。
用串口打点可以看到：复位发生在电机启动的那一瞬间。

**排查过程**：

| 步骤 | 怀疑对象 | 怎么排除的 | 结论 |
|---|---|---|---|
| 1 | 电机电流把电源拉垮 | 用**独立的**电源给电机（一个 12V 适配器），只共地 | **还是复位** → 不是"电源容量不够" |
| 2 | 电机换向火花 / EMI 辐射 | 在电机两端并一个 100nF 陶瓷电容 + 一个二极管 | 有改善但不彻底 |
| 3 | 地线上有压降 | 用万用表量"电机地"和"单片机地"两端 | 电机启动瞬间有**几十 mV 到几百 mV** 的跳动 🔬 |
| 4 | **接地拓扑** | 我原来的接法是"菊花链"：电源 → 单片机地 → 电机驱动地 → 电机地，一条线串下去 | 改成**星形**：所有地都单独回到电源的一个点 |
| 5 | 验证 | 改成星形后，电机启动不再复位 ✅ | 确认 |

**原因**（用第 2.5.3 节的公式算）：

地线不是理想导体，它有电阻和电感。假设我用的杜邦线大约 `0.2Ω/m` 的阻值，
菊花链那一段从电机地回到电源地的线是 20cm：

```text
R_wire ≈ 0.2Ω/m × 0.2m = 0.04Ω
```

电机启动电流假设是 1A（小电机）：

```text
直流压降 = 1A × 0.04Ω = 40mV
```

**40mV 本身不算什么。但真正的杀手是电感。**

20cm 的线大约 200nH（和坑 1 同一个量级）。电机启动时电流从 0 冲到 1A，
如果这个过程是 `1µs`（MOSFET 开关速度）：

```text
di/dt = 1A / 1µs = 1×10⁶ A/s
ΔV = L × di/dt = 200×10⁻⁹ × 1×10⁶ = 0.2V
```

**0.2V。** 而且这个 0.2V 是加在**地线**上的，意思是：
**在这几微秒里，单片机的"GND 参考点"比电源的 GND 高了 0.2V。**

单片机的所有电压判断都是相对它自己的 GND 做的，所以：

```text
单片机自己的 GND 抬高 0.2V → 对它来说 VDD 就"变低"了 0.2V
3.3V − 0.2V = 3.1V   ← 还在范围内
```

但这只是 1A 的情况。如果电机电流是 10A：

```text
ΔV = 10 × 1×10⁶ × 200×10⁻⁹ = 2V   ← 直接崩
```

而且真实的电机启动过程更糟：**换向 + 电刷火花会产生宽频噪声**，
这些噪声电流也会流过共用的地线，在地线上产生电压起伏。
**地线上的噪声会直接叠加到所有以这个地为参考的信号上**，
包括复位引脚、时钟、通信线。

**什么是菊花链，什么是星形：**

```text
   ❌ 菊花链（daisy chain）—— 电机电流流经单片机的地线

   电源 GND ──── 单片机 GND ──── 电机驱动 GND ──── 电机 GND
                     │                │
                 （单片机的              （电机的大电流
                   参考点）              流过这段线！）

   问题：电机电流 i 流经"单片机 GND → 电机驱动 GND"这一段，
        这段线的 L·di/dt 直接变成单片机参考点的电压波动。


   ✅ 星形（star ground）—— 每个模块的地单独回电源

                         ┌──── 单片机 GND
                         │
   电源 GND ────●────────┼──── 电机驱动 GND
              （单点）    │
                         └──── 电机 GND

   问题：单片机的地线里**没有电机电流**，所以电机再怎么折腾，
        单片机的参考点都是干净的。✅
```

**星形接地的核心原则**：

> **大电流回路的地，和小信号（单片机、传感器、ADC）的地，
> 必须在一点汇合，不能让大电流流经小信号的地线。**

⚠️ **一个延伸的问题：数字地和模拟地要不要分开？**

这是我目前只理解了一半的问题 🔬。原则是：**ADC 的模拟地（AGND）
应该单独走，最后在芯片下面一点连到数字地**（ST 的 AN2586 里有
关于 VDDA/VSSA 的处理建议）。**绝对不能**让 ADC 的参考地线上
流过大电流（比如 LED 的电流）。

但是"分地"做不好比不分更糟 —— 如果分开了却只在一个很远的地方连接，
回流电流被迫绕大圈，反而引入更大的干扰。所以：
**分地的关键是"分割但不隔离，且在正确的位置单点连接"。**
这一条我目前只有概念，没做过板子，不敢说会 🔬。

### 坑 3：ADC 读数偏高偏低不稳定，根因是"电源噪声透过分压电阻进来了"

**现象**：沿用第 03 章那个 `100k/10k` 的分压测电源电压，
在**没有电机**的干净环境下读数还行，但**一旦电机开始转**，
`v_bus` 就开始跳，而且比万用表实测值**偏高**（不是偏低）。

**原因分析**（这一条和第 03 章那个坑是两个不同的机制，值得分开记）：

第 03 章的坑是"**采样电容充不满**"，表现为**系统性偏低**。

这里的坑是"**噪声耦合**"，表现为**随机跳动且可能偏高**：

1. **分压电阻是一个"天线"。** `100k + 10k = 110kΩ` 的电阻串接在一个节点上，
   而这个节点又是高阻（`R_out = 9.09kΩ`）。电机换向产生的电磁噪声
   很容易通过空间耦合到这一段高阻走线上。
2. **噪声电压直接跟被测直流叠加。** ADC 采到的是"直流 + 噪声"，
   经过滑动平均后直流部分正确，**但整流效应会让平均值偏高**
   （噪声的正半周更容易让采样电容多充一点电，负半周因为二极管效应
   不容易"反向放电"）🔬 这一点我看到过解释，但没有实测验证。
3. **ADC 的输入保护二极管会被噪声触发。** 如果噪声尖峰超过 VDDA，
   输入端的保护二极管导通，把电荷注入内部节点，也会造成偏移。

**修法（按代价从低到高）**：

| 方法 | 具体做法 | 效果 | 代价 |
|---|---|---|---|
| 1. 降低分压电阻 | 100k/10k → 10k/1k | **最有效**：输出阻抗从 9.09kΩ 降到 909Ω，低阻节点抗耦合 | 多耗 1.09mA |
| 2. 并联电容 | 在 ADC 引脚对地并 **100nF** | 形成 RC 低通滤波，滤掉高频噪声 | 会引入延迟（`10k ∥ 1k = 909Ω × 100nF = 90.9µs`），对快速变化的电压不利 |
| 3. 加 RC 滤波 | 分压点 → 1kΩ → ADC 引脚，引脚对地 100nF | 二阶滤波，效果更好 | 多了两个元件，且 1kΩ 增加了源阻抗（但对 10k/1k 分压来说总阻抗仍可接受） |
| 4. 屏蔽 / 缩短走线 | 高阻节点走线尽量短，远离电机线 | 治本 | 布局限制 |
| 5. 软件滤波 | 中值滤波 + 滑动平均 | 抑制尖峰 | 治标，且会引入延迟 |

**第 2 条那个 RC 的时间常数要算清楚**（这是"加电容"最容易踩的反坑）：

```text
R_out = 10k ∥ 1k = 909Ω，C = 100nF
τ = 909Ω × 100nF = 90.9µs

如果电源电压在 10µs 内跌落 1V（电机启动），
ADC 引脚上的电压要在 90.9µs 之后才跟上 —— 慢了 9 倍
```

**所以电容不能随便加。** 如果这个电压是拿来做功率控制的前馈，
90.9µs 的延迟会让控制完全失步。**"加电容滤波"和"信号带宽"
永远是一个取舍**，跟 5.2 节讨论的窗口长度是同一回事，
只是一个在硬件上做、一个在软件上做。

### 7.1 观察去耦电容的效果（验证 2.1 节）

这个实验我在第 6 节坑 1 里做过，值得自己重复一遍。

1. 把最小系统板插在面包板上，写一个程序：
   **用 PA5 输出一个 500kHz 的方波**（用 TIM2_CH1 PWM，`psc=0, arr=143`，
   `f = 72MHz/(0+1)/(143+1) = 500kHz`），这样能制造持续的电流尖峰。
2. 同时在主循环里做一个"存活检测"：用一个计数器变量，每轮自增，
   每 500ms 用串口把计数器的值打出来。
3. **正常情况下**，串口的计数应该单调递增，不归零。
4. 现在找一个 100nF 电容，用**两根 20cm 的杜邦线**把它接到
   最小系统板的 3.3V 和 GND 排针上（故意接远）。
5. **预期现象** 🔬：串口打出的计数器会**随机归零**（说明单片机复位了），
   而且频率比不加电容时更高。
6. 把电容换成"直接插在板子排针旁边"（用最短的路径）。
7. **预期现象** 🔬：计数器不再归零。
8. 再把电容**拆掉**，只留板子自带的电容，看现象介于两者之间。

**这个实验想说明的**：电容的**位置**比它的**容量**更重要。
同样是 100nF，接在 2mm 处有效，接在 200mm 处反而可能有害
（那 20cm 的线本身就是一根天线）。

> **预期结果**，我只在坑 1 的情形下观察到过"复位频率变化"这个现象，
> 没有做过这个"500kHz 方波 + 20cm 电容"的定量对照实验。

### 7.2 LDO 的功耗与温升实测（验证 2.4.2 节）

这一步可以在面包板上做（🔬 待做）。

1. 取一颗可调/固定输出的线性稳压器（比如 AMS1117-3.3 或 LM1117-3.3，
   TO-220 封装）。
2. 输入接 12V，输出接一个**功率电阻当负载**，让负载电流是 500mA：
   ```text
   R_load = 3.3V / 0.5A = 6.6Ω
   功率 = 3.3V × 0.5A = 1.65W  →  至少要用 5W 的功率电阻
   ```
3. 通电，**用手背快速碰一下稳压器的金属片**（不要用手指捏，会烫伤）。
4. **预期现象** 🔬：几秒内就烫得不能碰。
5. 用万用表量输入电流：
   ```text
   预期 = 500mA（LDO 的输入电流 ≈ 输出电流）
   输入功率 = 12V × 0.5A = 6W
   ```
6. 算效率：`1.65W / 6W = 27.5%`。
7. **必须注意**：不要让它这样跑太久。这颗芯片在 4.35W 的损耗下会迅速升温，
   超过结温上限会触发热保护（输出掉下来）或者直接损坏。
   **这个实验最好用带散热片的，或者索性只做几秒钟。**

⚠️ **安全提醒**：这个实验里的稳压器会非常烫，一定有烫伤风险。
另外，12V × 0.5A 的输入如果短路，是有可能烧毁导线或者引起火灾的，
一定加保险丝。

### 7.3 搭一个电源电压监测电路（本章代码的完整复现）

1. **搭分压网络。** 取 `R1 = 100kΩ`、`R2 = 10kΩ`：
   ```text
   12V 电源 + ────[ 100kΩ ]────┬──── PA1
                               │
                            [ 10kΩ ]
                               │
                              GND
   ```
   ⚠️ 注意：**这里的分压比是 1/11**，所以 12V 时 PA1 上是 1.09V。
   如果你想测更高的电压（比如 24V），要么保证 `V_in < 3.3 × 11 = 36.3V`，
   要么重新设计分压比。
2. **确认共地。** 12V 电源的负极必须和最小系统板的 GND 连在一起，
   **否则分压不对，还可能损坏引脚**。
3. **CubeMX 配置**：

4. **接 USB-TTL**：TX→PA10，RX→PA9，GND 共地。
5. **编译烧录**，打开串口助手（115200 8N1）。
6. **预期现象** 🔬：每 1 秒左右打印一行，`v_bus` 应该接近万用表实测的电源电压。

8. **对照实验** 🔬：把 `V_ALARM_HYST` 改成 `0.0f`，重新烧录，
   在 10.5V 附近微调电源，观察 LED 是不是开始疯狂闪烁。
   **这个对照能非常直观地说明迟滞的必要性。**

### 7.4 用万用表估算线宽够不够（不需要 PCB）

## 8. 自测题（面试可能这么问）

### 题 1

**为什么 100nF 和 10µF 要并联，而不是只用一颗 10µF？**

**答**：

因为**真实电容不是理想电容**。实物是 `C + ESR + ESL` 串联，
阻抗表达式是：

```text
Z = ESR + jωL + 1/(jωC)
```

在低频，`1/(ωC)` 占主导（容性，频率越高阻抗越低）；
在高频，`ωL` 占主导（**感性，频率越高阻抗反而越高**）。
两者的交点就是自谐振频率：

```text
SRF = 1 / (2π√(LC))
```

算一下（`ESL` 取 0603 封装的典型值 0.5nH、0805 取 1nH）：

```text
100nF：SRF = 1/(2π√(0.5nH × 100nF)) = 1/(2π√(5×10⁻¹⁷)) ≈ 22.5MHz
10µF ：SRF = 1/(2π√(1nH × 10µF))   = 1/(2π√(1×10⁻¹⁴)) ≈ 1.59MHz
```

**10µF 在 1.59MHz 以上就变成"电感"了**，对 STM32 最关心的
几十 MHz ~ 几百 MHz 噪声完全无效。而 100nF 能一直管到 22.5MHz。

**而且换更大的容量救不了**：

```text
把 10µF 换成 100µF（ESL 还是 1nH）：
SRF = 1/(2π√(1nH × 100µF)) = 503kHz
```

**容量越大，SRF 越低。** 大电容只管低频。

**两个关键加分点**：

1. **多个相同容值并联不能展宽频段**。N 颗相同的电容并联，
   `C → N·C`、`L → L/N`，乘积 `L·C` 不变，
   **SRF 还是 22.5MHz，只是谷底阻抗降到 `ESR/N`**。
   所以必须**错开容值**（10µF / 1µF / 100nF / 10nF 这样）。
2. **并联有反谐振风险**。不同容值的电容并联时，在它们 SRF 之间
   会出现 LC 并联谐振的**阻抗尖峰**。如果尖峰落在噪声频段上，
   加电容反而更糟。

### 题 2（计算题）

**LDO 从 12V 降到 3.3V，带 500mA 负载，功耗和效率各是多少？
这样的设计能直接用吗？**

**答**：

LDO 是线性稳压，输入输出电流相同，多余的电压全部变成热：

```text
输出功率 P_out = 3.3V × 0.5A = 1.65W
输入功率 P_in  = 12V  × 0.5A = 6.0W
损耗    P_loss = (12 − 3.3)V × 0.5A = 8.7 × 0.5 = 4.35W

效率    η = P_out / P_in = 1.65 / 6.0 = 0.275 = 27.5%
```

**能不能直接用？用结温算一遍。**

TO-220 封装**不加散热片**时 `Rθ_JA ≈ 50 °C/W`，环境 25°C：

```text
T_junction = 25°C + 4.35W × 50°C/W = 25 + 217.5 = 242.5°C
```

而塑封器件最大结温一般 **125°C**（🔬 以数据手册 `T_J` max 为准）。
**242.5°C 远超上限，芯片会热保护关断或者直接损坏。**

**加一个 `Rθ_CA = 10 °C/W` 的散热片：**

```text
T_junction = 25 + 4.35 × (5 + 10) = 25 + 65.25 = 90.3°C   ← 勉强可以
```

但如果机箱内环境温度是 50°C：

```text
T_junction = 50 + 65.25 = 115.3°C   ← 几乎顶到 125°C，没有余量
```

**结论：这个设计不该用 LDO。** 正确做法是用 **DCDC 降压**：

```text
按 90% 效率算：P_in = 1.65/0.9 = 1.833W
              P_loss = 1.833 − 1.65 = 0.183W
对比 LDO 的 4.35W：0.183/4.35 = 0.0421 → 损耗降到约 1/24
```

（顺便说一句：效率从 27.5% 提到 90%，是 **3.3 倍**；
但损耗从 4.35W 降到 0.183W，是 **24 倍**。
**"省电"和"散热"是两笔账**，对小体积板子来说后者往往才是决定性的。）

**加分点**：如果后面还有一级需要低噪声的 3.3V（比如给 ADC 参考），
可以"DCDC 降到 5V，再用 LDO 从 5V 降到 3.3V"：
压差只有 1.7V，带 200mA 时损耗 `1.7 × 0.2 = 0.34W`，
效率 `3.3/5 = 66%`，**绝对损耗小、纹波又被 LDO 的 PSRR 压掉** —— 
这就是典型的"两级供电"结构。

### 题 3（计算题）

**1oz 铜、1mm 线宽的外层走线，能过多少电流？如果我要过 10A 怎么办？**

**答**：

**先算截面积。** 1oz 铜厚度 35µm = 1.378mil：

```text
1mm = 39.37mil
A = 39.37 × 1.378 = 54.25 mil²
```

**按 IPC-2221 的外层公式（ΔT = 10°C）：**

```text
I = 0.048 × ΔT^0.44 × A^0.725
  = 0.048 × 10^0.44 × 54.25^0.725
  = 0.048 × 2.754 × 18.10
  = 2.39A
```

**公式给出 2.39A**，但工程上按 **1A/mm** 用（降额，因为公式没算阻焊盖层、
过孔瓶颈、工艺偏差）。**所以答案是：1mm 线宽按 1A 设计。**

**要过 10A，四条路（按推荐顺序）：**

1. **加宽 + 2oz 铜**。2oz 铜厚翻倍，载流能力大约提升 `2^0.725 = 1.65` 倍，
   加上线宽加宽：
   ```text
   2oz、3mm 线宽：A = 118.1 × 2.756 = 325.5 mil²
   I = 0.048 × 2.754 × 325.5^0.725
   325.5^0.725: ln(325.5)=5.785, ×0.725=4.194, e^4.194=66.3
   I = 0.048 × 2.754 × 66.3 = 8.76A
   ```
   按 1A/mm 降额折算约 3.7A。**还是不够 10A。**

2. **多层并联**。同一网络在 4 层上各走 3mm、2oz，载流叠加大约 4 倍。

3. **开窗加锡**。阻焊开窗后在走线上堆锡，等效截面积能增大 2~3 倍。

4. **⭐ 直接用导线。** 这是机器人上真实的做法 —— 10A 以上的主回路
   根本不用 PCB 走线，而是用导线 + 接线端子或铜排。
   ```text
   按 5 A/mm² 的电流密度：S = 10/5 = 2mm²  →  AWG 14（2.08mm²）
   ```

**再算一遍压降，看看为什么 10A 走 PCB 这么难。** 50mm 长的 1mm 走线：

```text
R = ρL/S = 1.72×10⁻⁸ × 0.05 / 3.5×10⁻⁸ = 24.6mΩ

10A 时：ΔV = 10 × 0.0246 = 0.246V    P = 100 × 0.0246 = 2.46W
```

**2.46W 集中在 50mm × 1mm 的一条铜上**，温升远超 10°C。
而 20A 时是 `ΔV = 0.49V`、`P = 9.85W` —— 必烧。

**面试加分点**：主动提"**过孔是载流瓶颈**"。
一个 0.3mm 孔径、1oz 铜的过孔，载流能力大概只有 0.5~1A，
所以大电流换层要打**多个过孔**（并联），或者干脆不换层。

### 题 4

**为什么超级电容必须做均压？举个例子说明不均压会出什么问题。**

**答**：

**根本原因：单体电压太低，必须串联。**

```text
单体额定 2.7V，要做 24V 母线：24 / 2.7 = 8.89 → 至少 9~10 节串联
```

串联时**每一节流过的电荷是相同的**，但各节的参数不可能一致：

1. **容量公差大**。超级电容的容量公差常见是 `−10% / +30%`（🔬 以规格书为准）。
   ```text
   V = Q / C，电荷 Q 相同、容量 C 不同 → 容量小的那节电压更高
   ```
2. **漏电流不同**。每节都有 μA 级漏电流，长期静置时漏得慢的那节电压会爬高。
3. **初始电压不同**。上次放电没放干净。

**举个数**：10 节串联，总电压充到 27V（平均每节 2.7V）。
其中一节容量只有标称的 90%，其他都是 100%：

```text
其他 9 节：V = 2.66V
容量小的那节：V = 2.66 × (1/0.9) = 2.96V
```

**2.96V > 2.7V 额定电压。** 超级电容超过额定电压会导致
**电解液分解、产气、内阻上升、寿命暴跌，严重的会鼓包漏液**。
而且这是个**正反馈**：内阻上升 → 同样的电流下发热更多 → 漏电流更大 → 
电压更不均。

**均压方案两种：**

| | 被动均压 | 主动均压 |
|---|---|---|
| 做法 | 每节并一个电阻（或加稳压管/比较器） | 用双向 DC-DC / 电荷泵把电荷从高电压节搬到低电压节 |
| 原理 | 电压高的节在电阻上泄放更多电流 | 能量转移，不浪费 |
| 成本 | 极低 | 高 |
| 效率 | 差（多余能量全变热） | 高 |
| 静态功耗 | **有**（一直发热） | 只在工作时 |
| 复杂度 | 低 | 高（要专用 IC） |

**被动均压的功耗要算一笔账**（10 节、每节并 100Ω、充满时每节 2.7V）：

```text
单节电流 = 2.7V / 100Ω = 27mA
单节发热 = 2.7V × 0.027A = 0.073W
10 节合计 = 0.73W   ← 一直发热
```

**0.73W 的持续静态功耗**，这就是"均压电阻不能选太小"的原因 —— 
均压速度和静态功耗之间要取舍。

**加分点**：能说出"**均压是超级电容管理系统（CMS）必须有的功能**"，
并且知道它需要**逐节电压采样**，而逐节采样有个大难点：
**串联后的每一节是浮地的**（第 8 节的"地"跟系统 GND 差十几伏），
不能用普通单端 ADC 直接测。**能意识到这个问题，说明真的想过怎么做。**

### 题 5（计算题）

**一个 10 节串联的超级电容组，单体 100F/2.7V、内阻 10mΩ，
回路导线+接插件电阻 50mΩ。直接接到 24V 电源上，浪涌电流多大？
为什么必须做缓启动？**

**答**：

**先算回路总电阻。**

```text
10 节串联的内阻 = 10 × 10mΩ = 100mΩ
导线 + 接插件 = 50mΩ
R_total = 100 + 50 = 150mΩ = 0.15Ω
```

**上电瞬间，电容电压还是 0V，所以整个 24V 都加在 0.15Ω 上：**

```text
I_inrush = 24V / 0.15Ω = 160A
```

**160 安培。** 后果有四个：

1. **保险丝瞬间熔断**。30A 的保险丝在 160A 下大概几毫秒就断了。
   ```text
   保险丝的 I²t 值：160² × t = 熔断所需能量
   —— 160A 是额定值 5.3 倍，按典型熔断曲线是毫秒级
   ```
2. **接插件打火、氧化、甚至熔焊**。
3. **电源被拉进过流保护**，直接关机或反复重启（如果是 DCDC 供电）。
4. **`L·di/dt` 过压**。回路电感上产生巨大尖峰，可能击穿器件。

**用 NTC 热敏电阻（冷态 5Ω）**：

```text
I_inrush = 24 / (0.15 + 5) = 24 / 5.15 = 4.66A    ← 降到 1/34
```

**但 NTC 对超级电容不合适**：

```text
充电时间常数 τ = R × C = 5.15Ω × (100F/10) = 5.15 × 10 = 51.5 秒
```

（10 节 100F 串联，等效容量是 `100F/10 = 10F`。）

```text
完全充满需要 5τ = 257 秒 ≈ 4.3 分钟
```

**4.3 分钟** —— 而且 NTC 自己在启动的瞬间发热
（`4.66² × 5 = 108W` 的瞬时发热），几秒内阻值就从 5Ω 掉到 1Ω 以下，
**失去限流作用**。所以 NTC 只适合"µF~mF 级输入电容"的场合。

**用 PMOS + RC 缓启动（正确方案）**：

```text
R2 = 100kΩ、C1 = 1µF
τ = R2 × C1 = 100×10³ × 1×10⁻⁶ = 0.1 秒
完全导通约 3~5τ = 0.3 ~ 0.5 秒
```

PMOS 从"关断"平滑过渡到"完全导通"，把浪涌电流限制在一个安全值。
粗估（🔬 必须查 MOSFET 的 SOA 曲线确认）：

```text
假设过渡期平均等效电阻 10Ω：
I_peak ≈ 24 / (0.15 + 10) = 2.37A
```

**关键是稳态时 MOSFET 完全导通，`R_DS(on)` 只有几 mΩ，几乎不发热、不损耗能量**
—— 这是它比 NTC 好的核心原因。

**但要注意瞬时功耗**：过渡期 MOSFET 上同时有电压和电流：

```text
若某时刻 10V × 2.3A = 23W，持续 0.1s → 2.3 焦耳要在硅片里耗散
```

**必须查 MOSFET 数据手册的 SOA（Safe Operating Area）曲线**，
确认"24V、2.3A、0.1s"这个工作点在安全区内。这一步我现在还不会看 🔬。

**无论用哪种缓启动，主回路都必须有保险丝**，因为缓启动电路
管不了"负载短路"这类故障。

### 题 6

**PCB 上为什么要尽量铺完整的地？如果地平面被一条走线切断了会怎样？**

**答**：

**因为信号电流一定要流回来，而回流电流走的是"回路面积最小"的路径。**

在 PCB 上，信号走线正下方如果有连续的地平面，回流电流会**紧贴着信号线正下方**
走相反方向：

```text
   信号走线 ─────────────────────────▶
   ═══════════════════════════════════   ← 地平面（紧邻，间距 = 介质厚度，0.2mm 级）
   回流电流 ◀─────────────────────────
```

回路的面积 = `走线长度 × 介质厚度`，**非常小** →
`L` 小 → `ΔV = L·di/dt` 小 → EMI 小、抗干扰强。

**地平面被切断（开槽、被别的走线横穿）**：

回流电流不能从正下方过去，必须**绕行**：

```text
   信号走线 ──────────▶  ┌──── 地平面被切断
                        │
   回流绕行 ◀───────────┘    ← 回路面积暴增
```

**两个后果**：

1. **EMI 陡增**。回路面积从"长 × 0.2mm"变成"长 × 几 mm"，
   辐射和敏感度都上升。按辐射正比于回路面积估，面积大 20 倍 → 辐射强 26dB。
2. **信号完整性变差**。回流路径绕行意味着信号看到的**阻抗不再是
   受控阻抗**（它突然变大），产生反射、过冲、振铃。
   高速信号（SPI、USB、时钟）会直接出问题。

**双层板为什么要"一面尽量铺完整地"**：

- 双层板只有两层铜，做不了"信号—地—电源"的三明治；
- 所以退而求其次：**一面集中走线，另一面大面积铺地**；
- 关键高频线（晶振、SWD、SPI）下方必须有**连续**的地，
  **绝不能在它正下方横穿别的信号线**。

**加分点**：能说出**晶振（HSE 8MHz）**的具体处理 ——
虽然只有 8MHz，但边沿陡、谐波高，ST 的参考设计会在晶振周围
放一圈接地过孔、下方铺完整地、外围加负载电容就近接地，
**就是为了让这个高频回路尽可能小**。

### 题 7（设计题）

**设计一块"STM32 最小系统板 + 电源"的 PCB，说明你的电源和去耦方案。**

**答**：

**整体供电架构**（按 2.4.4 节的取舍逻辑）：

```text
  12V 输入
     │
     ├─[ 保险丝 2A ]─[ PMOS 缓启动 ]─[ π 型滤波 ]─┬─▶ 12V 输出（给外部）
     │                                            │
     │                                      [ DCDC 12V→5V ]
     │                                            │
     │                                      5V 母线
     │                                            │
     │                                      [ LDO 5V→3.3V ]
     │                                            │
     │                                        3.3V 母线
     │                                            │
     └───────────────────────────────────▶ STM32 VDD ×4 / VDDA
```

**为什么这么分**：

- 12V → 5V 压差 7V，如果带 1A，LDO 损耗 `7 × 1 = 7W`，**绝对不行** → 必须 DCDC；
- 5V → 3.3V 压差 1.7V，带 200mA 损耗 `1.7 × 0.2 = 0.34W`，效率 66%，
  **绝对损耗可接受，且 LDO 的 PSRR 能把 DCDC 的开关纹波压下去** → 用 LDO。

**去耦方案（按 2.2 节"错开容值覆盖频段"的原则）：**

| 位置 | 容值 | 封装 | 理由 | SRF（算出来的） |
|---|---|---|---|---|
| 12V 输入 | 10µF + 100nF | 0805 + 0603 | 输入大容量储能 + 高频 | 1.59MHz / 22.5MHz |
| DCDC 输入 | 10µF ×2 | 0805 | 开关电源的输入纹波电流大，要足量 | — |
| DCDC 输出 | 22µF + 100nF | 0805 + 0603 | 输出储能 + 高频 | — |
| 5V 母线 | 10µF + 1µF + 100nF | 0805/0603 | 覆盖三个频段 | 1.59M / 6.5M / 22.5MHz |
| **3.3V 每个 VDD 引脚** | **100nF** | 0603 | AN2586 的建议 | 22.5MHz |
| 3.3V 整体 | 4.7µF | 0805 | 全局储能 | 2.3MHz |
| **VDDA / VREF+** | **1µF + 10nF** | 0603/0402 | **模拟电源单独滤波，且用磁珠与数字电源隔离** | 6.5M / 79.6MHz |

**布局规则（我自己会遵守的）：**

1. 每个 VDD 引脚的 100nF **紧贴引脚，走线 < 2mm**，地过孔就近打（< 1mm）；
2. **先过电容再进引脚**（穿越式，不是分支式）；
3. DCDC 的**开关节点（SW）面积做到最小**，它是 `dv/dt` 最高的节点，
   是最大的辐射源；输入电容紧贴 DCDC 的 VIN 引脚；
4. **电感放在 DCDC 的同一面**，不要跨层走，避免过孔带来的额外电感；
5. **模拟区（VDDA、晶振、ADC 输入）和数字区分开**，
   模拟地用 `VSSA` 单独引出，在芯片下方一点连到数字地；
6. **晶振周围铺地 + 一圈接地过孔**，负载电容就近接地；
7. **大电流路径（12V → DCDC → 5V 的输入输出）走线加宽**，
   按 1A/mm 算，或者直接开窗加锡；
8. **SWD 调试口（PA13/PA14）尽量短**。

**我目前不会做的部分（必须诚实说明）** 🔬：

- **不会做阻抗控制**（USB、CSI 这类需要 90Ω/100Ω 差分阻抗的走线，
  要算叠层、线宽、间距，我没学过）；
- **不会做电源完整性仿真**（PDN 阻抗曲线、反谐振峰，
  要用 SIwave 这类工具）；
- **没有示波器**，所以做出来的板子我**无法定量验证**纹波和瞬态响应，
  只能靠"能不能跑"来判断；
- **没画过板、没打样过**（这一条写在 BNGU 招新对照表的短板里）。

**所以这一题的答案，我只能给到"按原理推导的设计方案"这个层面，
不能给"我做过、验证过的方案"。** 这是我现在和真正能做硬件的人之间最大的差距，
也是我下一步要补的东西。
